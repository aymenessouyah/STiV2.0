Récapitulatif JavaScript

Synthèse complète pour revoir les bases de JavaScript, les structures de contrôle, les fonctions, les chaînes, les tableaux, le DOM, les événements et la validation d’un formulaire.

1. Rôle de JavaScript

JavaScript est un langage de programmation exécuté principalement dans le navigateur. Il rend une page web dynamique et interactive.

HTML

Structure le contenu : titres, paragraphes, formulaires, tableaux, images.

CSS

Gère la présentation : couleurs, tailles, marges, disposition, responsive.

JavaScript

Gère le comportement : calculs, réactions aux clics, vérifications, mise à jour du DOM.

En STI, JavaScript est très utilisé pour lire les valeurs d’un formulaire, vérifier les données saisies, afficher un résultat et modifier le contenu d’une page sans la recharger.

2. Où écrire le code JavaScript ?

Dans la page HTML

<script>
  alert("Bienvenue en STI");
</script>

Dans un fichier externe

<script src="script.js"></script>
Le fichier externe est recommandé pour séparer la structure HTML et le code JS.

3. Variables et types de données

let

Variable modifiable, portée de bloc.

let note = 15.5;
note = 17;

const

Constante : sa référence ne peut pas être réaffectée.

const coeff = 3;

var

Ancienne déclaration, encore présente dans plusieurs exercices.

var nom = "Ali";
Type Exemple Description Test avec typeof
Number 18, 12.75 Nombre entier ou réel "number"
String "Bac STI" Chaîne de caractères "string"
Boolean true, false Valeur logique "boolean"
Array [10, 14, 16] Tableau de valeurs "object"
Object {nom:"Sami", age:18} Ensemble de propriétés "object"
Une valeur lue depuis un champ de formulaire (input.value) ou prompt() est toujours une chaîne de caractères. Pour calculer, utilisez Number(), parseInt() ou parseFloat().

8. Chaînes de caractères (String)

Propriétés et méthodes utiles (Programme STI)

  • ch.length : longueur de la chaîne
  • ch.toUpperCase() / ch.toLowerCase()
  • ch.trim() : supprime les espaces au début et à la fin
  • ch[i] : caractère à la position i (et ch.charCodeAt(i))
  • ch.indexOf(s) / ch.lastIndexOf(s) : position d’une sous-chaîne (-1 si absente)
  • ch.substring(d, f) : extrait une sous-chaîne de d à f - 1
  • ch.replace(a, b) : remplace a par b

Exemple

let ch = "Informatique";
ch.length;            // 12
ch.toUpperCase();     // "INFORMATIQUE"
ch.substring(0, 4);   // "Info"
ch.indexOf("mat");    // 5

10. Manipulation du DOM

Le DOM (Document Object Model) représente les éléments HTML sous forme d’objets manipulables en JavaScript.

Sélectionner un élément

let el = document.getElementById("message");
let champ = document.querySelector("#nom");
let items = document.querySelectorAll(".item");

Lire / modifier

let nom = document.getElementById("nom").value;
el.textContent = "Bonjour " + nom;
el.style.color = "#f7df1e";

11. Les événements

Un événement est une action détectée par le navigateur : clic, saisie, changement de valeur, envoi de formulaire, chargement.

Événements fréquents

  • click : clic sur un bouton
  • input : saisie en direct dans un champ
  • change : changement de sélection
  • submit : envoi d’un formulaire

addEventListener

const btn = document.getElementById("btn");
btn.addEventListener("click", function () {
  alert("Bouton cliqué !");
});

12. Exemple complet : validation d’un formulaire STI

Tester la validation

Remplissez les champs puis cliquez sur « Vérifier le formulaire ».

Principe de contrôle en STI

function estChiffres(ch) {
  for (let i = 0; i < ch.length; i++) {
    if (ch[i] < "0" || ch[i] > "9") return false;
  }
  return ch.length > 0;
}

function verifier() {
  let cin = document.getElementById("fCin").value.trim();
  let note = Number(document.getElementById("fNote").value);

  if (cin.length != 8 || !estChiffres(cin)) {
    alert("Le CIN doit contenir 8 chiffres.");
    return false;
  }
  if (isNaN(note) || note < 0 || note > 20) {
    alert("La note doit être comprise entre 0 et 20.");
    return false;
  }
  return true;
}
