1. Introduction et emplacement du code

À quoi sert JavaScript ?

JavaScript permet de rendre une page interactive : calculer, réagir à un clic, vérifier une saisie, modifier le contenu HTML et changer le style.

Script interne

<script>
  alert("Bonjour STI !");
</script>

Placer souvent le script avant </body> pour que les éléments HTML soient déjà chargés.

Script externe

<script src="script.js"></script>

Le code est enregistré dans un fichier séparé nommé par exemple script.js.

Afficher une information

console.log("Message");
alert("Attention !");
let nom = prompt("Votre nom ?");
console.log(nom);

console.log() affiche dans la console, alert() ouvre une boîte de dialogue et prompt() demande une saisie.

2. Variables, constantes et types

Déclarer des variables

let age = 17;
let nom = "Amira";
let admis = true;
const PI = 3.14159;
var ancien = "ancienne syntaxe";
  • let : valeur réaffectable.
  • const : variable non réaffectable.
  • var : ancienne déclaration, portée différente.

Types principaux

let n = 12;             // number
let prix = 8.5;         // number
let texte = "Bonjour";  // string
let ok = false;         // boolean
let vide;               // undefined
let rien = null;        // absence volontaire de valeur

JavaScript est à typage dynamique : le type dépend de la valeur affectée.

Règles de nommage

  • Commencer par une lettre, _ ou $.
  • Ne pas commencer par un chiffre.
  • Respecter les majuscules et minuscules : note et Note sont différentes.
  • Éviter les mots réservés.
let noteEleve = 15;
let _compteur = 0;

Conversions de types : principe

Convertir signifie transformer une valeur d’un type vers un autre : chaîne (string), nombre (number) ou booléen (boolean).

let texte = "25";          // string
let nombre = Number(texte); // number : 25
let resultat = nombre + 5;  // 30
Attention : "25" + 5 donne "255" (concaténation), tandis que Number("25") + 5 donne 30 (addition numérique).

À comprendre : le signe +, la multiplication et la soustraction

Lorsqu’une chaîne numérique est associée à un nombre, JavaScript ne réagit pas de la même manière selon l’opérateur utilisé. Le signe + peut concaténer des chaînes, tandis que * et - effectuent des calculs numériques et convertissent ici automatiquement les chaînes numériques en nombres.

ExpressionRésultatPourquoi ?
5 + "6""56"Concaténation : le nombre 5 est associé au texte "6".
"6" + 5"65"Concaténation, dans l’ordre des opérandes.
5 * "6"30La chaîne "6" est convertie en nombre.
"5" * 630La chaîne "5" est convertie en nombre.
5 - "6"-1La chaîne "6" est convertie en nombre.
"5" - 6-1La chaîne "5" est convertie en nombre.
console.log(5 + "6"); // "56" : string
console.log("6" + 5); // "65" : string
console.log(5 * "6"); // 30 : number
console.log("5" * 6); // 30 : number
console.log(5 - "6"); // -1 : number
console.log("5" - 6); // -1 : number

console.log(typeof (5 + "6")); // "string"
console.log(typeof (5 * "6")); // "number"
Règle importante : "56" est une chaîne de caractères, alors que 56 est un nombre. Pour obtenir une addition numérique, convertir explicitement la chaîne : 5 + Number("6") donne 11.

1. Number() — convertir en nombre

Number("42")       // 42
Number("3.5")      // 3.5
Number("")         // 0
Number("   ")      // 0
Number("42abc")    // NaN
Number("bonjour")  // NaN
Number(true)       // 1
Number(false)      // 0
Number(null)       // 0
Number(undefined)  // NaN

Number() tente de convertir toute la valeur. Si la chaîne ne représente pas un nombre valide, le résultat est NaN (« Not a Number »).

2. parseInt() — lire un entier

parseInt("27")       // 27
parseInt("27.9")     // 27
parseInt("-8")       // -8
parseInt("27abc")    // 27
parseInt("abc27")    // NaN
parseInt("3.14")     // 3

parseInt() lit un entier au début de la chaîne et s’arrête lorsqu’il rencontre un caractère incompatible. Pour une base décimale, on peut écrire parseInt(texte, 10).

3. parseFloat() — lire un nombre décimal

parseFloat("27.8")    // 27.8
parseFloat("-2.5")    // -2.5
parseFloat("27.8abc") // 27.8
parseFloat("abc27.8") // NaN
parseFloat("12")      // 12

En JavaScript, le séparateur décimal dans une chaîne numérique est le point : "3.5". La virgule de "3,5" ne constitue pas un séparateur décimal reconnu par ces conversions.

4. String() — convertir en chaîne

String(25)        // "25"
String(3.14)      // "3.14"
String(true)      // "true"
String(false)     // "false"
String(null)      // "null"
String(undefined) // "undefined"

Utile pour obtenir une représentation textuelle d’une valeur. La concaténation avec + peut également transformer un nombre en chaîne lorsqu’un des opérandes est une chaîne.

5. Boolean() — convertir en booléen

Boolean(1)         // true
Boolean(-5)        // true
Boolean("Bonjour") // true
Boolean(0)         // false
Boolean("")        // false
Boolean(null)      // false
Boolean(undefined) // false
Boolean(NaN)       // false

Valeurs considérées comme fausses : false, 0, -0, "", null, undefined et NaN. Les autres valeurs sont généralement vraies, y compris "0" et "false".

6. La valeur NaN

let n = Number("12abc"); // NaN
Number.isNaN(n);         // true
isNaN("bonjour");        // true, après conversion

NaN indique qu’une opération numérique n’a pas produit un nombre valide. Pour tester précisément une valeur déjà calculée, préférer Number.isNaN().

7. Les saisies avec prompt()

let ageTexte = prompt("Votre âge ?");
let age = Number(ageTexte);

if (ageTexte !== null && ageTexte.trim() !== "" && Number.isFinite(age)) {
  console.log("L'année prochaine : " + (age + 1));
} else {
  console.log("Saisie numérique invalide.");
}

prompt() renvoie une chaîne si l’utilisateur saisit une valeur, et null s’il annule. Vérifier aussi la chaîne vide : Number("") vaut 0.

4. Structures conditionnelles

if / else

if (note >= 10) {
  resultat = "Admis";
} else {
  resultat = "Ajourné";
}

if / else if / else

if (note >= 16) {
  mention = "Très bien";
} else if (note >= 14) {
  mention = "Bien";
} else if (note >= 12) {
  mention = "Assez bien";
} else {
  mention = "À travailler";
}

Les conditions sont évaluées dans l’ordre. La première vraie est exécutée.

switch

switch (jour) {
  case 0:
    nomJour = "Dimanche";
    break;
  case 6:
    nomJour = "Samedi";
    break;
  default:
    nomJour = "Jour ouvré";
}

Utiliser break pour éviter de poursuivre dans le cas suivant.

Opérateur ternaire

let resultat = note >= 10 ? "Admis" : "Ajourné";

Forme courte d’un if / else pour une expression simple.

5. Boucles

while

let i = 1;
while (i <= 5) {
  console.log(i);
  i++;
}

La condition est testée avant chaque tour. Si elle est fausse au départ, le corps ne s’exécute pas.

do ... while

let i = 1;
do {
  console.log(i);
  i++;
} while (i <= 5);

Le corps s’exécute au moins une fois, puis la condition est testée.

for

for (let i = 1; i <= 5; i++) {
  console.log(i);
}

Initialisation ; condition ; mise à jour. Très pratique quand le nombre de répétitions est connu.

break et continue

for (let i = 1; i <= 10; i++) {
  if (i === 5) continue;
  if (i === 8) break;
  console.log(i);
}

continue passe au tour suivant ; break quitte la boucle.

6. Fonctions

Déclaration et appel

function saluer(nom) {
  return "Bonjour " + nom;
}
let message = saluer("Amira");
console.log(message);

Les paramètres reçoivent les données ; return renvoie le résultat.

Paramètres par défaut

function multiplier(a, b = 2) {
  return a * b;
}
multiplier(4);    // 8
multiplier(4, 3); // 12

Fonction anonyme et fléchée

const carre = function (n) {
  return n * n;
};

const double = n => n * 2;

Portée

Une variable déclarée dans une fonction est locale à cette fonction. Une variable déclarée dans un bloc avec let ou const est limitée à ce bloc.

let total = 10;
function exemple() {
  let local = 3;
  return total + local;
}

7. Tableaux

Créer et accéder

let notes = [12, 15, 9, 18];
notes[0];          // 12
notes[2] = 10;
notes.length;      // 4

Les indices commencent à 0. Le dernier indice vaut généralement length - 1.

Méthodes courantes

notes.push(14);    // ajouter à la fin
notes.pop();       // retirer le dernier
notes.unshift(8);  // ajouter au début
notes.shift();     // retirer le premier
notes.includes(15); // tester la présence

Parcourir un tableau

for (let i = 0; i < notes.length; i++) {
  console.log(notes[i]);
}

for (const note of notes) {
  console.log(note);
}

Tableau et calcul

let somme = 0;
for (let i = 0; i < notes.length; i++) {
  somme += notes[i];
}
let moyenne = somme / notes.length;

Vérifier que le tableau n’est pas vide avant de calculer une moyenne.

8. Chaînes de caractères

Créer et concaténer

let prenom = "Amira";
let nom = "Ben Ali";
let complet = prenom + " " + nom;
let phrase = `Bonjour ${prenom} !`;

Les apostrophes, guillemets et accents font partie du texte ; les chaînes sont indexées à partir de 0.

Propriétés et méthodes

let s = "Bonjour STI";
s.length;              // longueur
s.toUpperCase();       // majuscules
s.toLowerCase();       // minuscules
s.includes("STI");     // true
s.indexOf("jour");     // position ou -1
s.slice(0, 7);         // "Bonjour"
s.trim();              // retirer espaces aux extrémités
s.replace("STI", "SI");

Parcourir les caractères

let mot = "STI";
for (let i = 0; i < mot.length; i++) {
  console.log(mot[i]);
}

On peut accéder à un caractère avec son indice, par exemple mot[i].

10. DOM : accéder et modifier la page

Sélectionner un élément

document.getElementById("titre");
document.querySelector(".carte");
document.querySelectorAll("p");

getElementById() cible un identifiant ; querySelector() renvoie le premier élément correspondant au sélecteur CSS.

Modifier le contenu

let p = document.getElementById("message");
p.textContent = "Nouveau texte";
p.innerHTML = "<strong>Important</strong>";

Utiliser textContent pour afficher du texte brut. innerHTML interprète du HTML et doit être utilisé avec prudence.

Modifier le style et les classes

p.style.color = "tomato";
p.style.fontSize = "20px";
p.classList.add("actif");
p.classList.remove("actif");
p.classList.toggle("actif");

Créer un élément

let li = document.createElement("li");
li.textContent = "Nouvel élément";
document.querySelector("ul").appendChild(li);

12. Formulaires et validation

Lire une valeur

let champ = document.getElementById("nom");
let valeur = champ.value;

value contient la valeur saisie. Pour un champ numérique, convertir avec Number().

Vérifier une saisie

let nom = document.getElementById("nom").value.trim();

if (nom === "") {
  document.getElementById("erreur").textContent =
    "Le nom est obligatoire.";
} else {
  document.getElementById("erreur").textContent =
    "Saisie correcte.";
}

Empêcher l’envoi si invalide

form.addEventListener("submit", function (event) {
  if (champ.value.trim() === "") {
    event.preventDefault();
    message.textContent = "Champ obligatoire";
  }
});

preventDefault() empêche l’action habituelle, ici l’envoi du formulaire, si la validation échoue.

13. Erreurs, débogage et bonnes habitudes

Repérer les erreurs

  • Ouvrir les outils de développement du navigateur (F12).
  • Lire l’onglet Console.
  • Utiliser console.log() pour suivre les valeurs.
  • Vérifier l’orthographe des identifiants et les parenthèses/accolades.

Erreurs fréquentes

let note = 12;       // déclaration
if (note >= 10) {    // condition
  console.log("Admis");
}

let total = Number("15"); // conversion

Un = affecte une valeur ; === compare. Respecter les majuscules/minuscules.

Bonnes pratiques

  • Utiliser des noms explicites.
  • Indenter le code régulièrement.
  • Préférer let et const à var dans du nouveau code.
  • Vérifier les valeurs saisies par l’utilisateur.
  • Tester les cas normaux et les cas limites.

Rappel important

JavaScript s’exécute côté navigateur, mais une validation côté client ne remplace pas une validation côté serveur pour les données sensibles.
