01 1. Éléments d'en-tête / 1er niveau

Balise Description Attributs principaux
<html> Racine du document HTML. Tout autre élément doit être son descendant. la langue d'affichage des mois dans un champ <input type="month"> ou <input type="date" /> ne dépend pas de l'attribut lang="en" du code HTML. Elle dépend uniquement des paramètres linguistiques du navigateur ou du système d'exploitation de l'utilisateur lang="fr"
<head> Fournit des informations générales (métadonnées), incluant son titre et des liens CSS/JS. -
<body> Indique au navigateur où commence et où se termine le corps de votre page. -
<link> Définit la relation entre le document et une ressource externe (feuille de style CSS, favicons). href, rel, type
<meta> Représente toute métadonnée (charset UTF-8, viewport responsive, etc.). charset, name, content, http-equiv
<script> Utilisé pour intégrer ou faire référence à un script exécutable (JavaScript). src, type
<style> Définit les informations de style (CSS) internes pour un document. type, media
<title> Définit le titre du document affiché dans l'onglet du navigateur. -

04 4. Listes (<ul>, <ol>, <li>)

Balise Description Attributs spécifiques
<ul> Définit une liste à puces (non ordonnée). -
<ol> Définit une liste ordonnée (numérotée). type ("a", "A", "i", "I", "1"), start, reversed
<li> Définit un élément individuel dans une liste. -
exemple.html
<!-- Liste non ordonnée (<ul>) -->
<h3>Nos catégories de fleurs :</h3>
<ul>
    <li>Orchidées</li>
    <li>Tulipes</li>
    <li>Roses rouges</li>
</ul>

<!-- Liste ordonnée (<ol>) avec type d'affichage -->
<h3>Étapes pour passer une commande :</h3>
<ol type="1" start="1">
    <li>Choisir les fleurs</li>
    <li>Saisir l'adresse de livraison</li>
    <li>Valider le paiement</li>
</ol>

Nos catégories de fleurs (<ul>) :

  • Orchidées
  • Tulipes
  • Roses rouges

Étapes pour passer une commande (<ol>) :

  1. Choisir les fleurs
  2. Saisir l'adresse de livraison

06 6. Structuration de texte & média

Balise Description Attributs majeurs
<p> Paragraphe. -
<pre> Texte préformaté (conserve exactement les espaces et retours à la ligne). -
<h1> à <h6> Titres de niveau 1 à 6. -
<hr> / <br> Ligne horizontale de séparation / Saut de ligne. -
<img> Image. src, alt, width, height, title
<figure> / <figcaption> Média autonome (Image, Vidéo, Audio) et sa légende. -
<audio> / <video> Contenu audio et vidéo. src, controls, autoplay, loop, width, height
<a> Lien hypertexte. href, target ("_blank", "_self", "_parent", "_top")
<mark> Texte surligné. -
<details> / <summary> Bloc dépliant interactif et son en-tête. open

Exemples concrets : Éléments <figure> avec <img>, <video> et <audio>

exemple.html

</figure>

<!-- 2. Figure avec Vidéo -->

    <video src="presentation.mp4" controls width="320" height="180">
        Votre navigateur ne supporte pas la vidéo HTML5.

    <figcaption>Fig.2 - Présentation vidéo de la boutique.</figcaption>
</figure>

<!-- 3. Figure avec Audio -->

    </audio>

07 7. Attributs Globaux & Événements

Attributs Globaux

  • class : Nom de classe CSS.
  • id : Identifiant unique de l'élément.
  • style : Style CSS en ligne.
  • lang : Code langue du contenu.
  • hidden : Masque l'élément visuellement.
  • title : Info-bulle explicative au survol.

Événements JavaScript

🖱️ Souris

  • onclick : Se déclenche lors d'un clic sur l'élément.
  • onmouseover : Se déclenche lorsque le pointeur de la souris survole l'élément.
  • onmouseout : Se déclenche lorsque le pointeur de la souris sort de l'élément.

⌨️ Clavier

  • onkeydown : Se déclenche lorsqu'une touche du clavier est pressée.
  • onkeyup : Se déclenche lorsqu'une touche est relâchée.

📝 Champs & Formulaires

  • onfocus : Se déclenche au moment où l'élément obtient le focus.
  • onblur : Se déclenche au moment où l'élément perd le focus.
  • oninput : Se déclenche dès que la valeur d'un élément a changé.
  • onchange : Se déclenche lorsque la valeur d'un élément est modifiée.
  • onsubmit : Se déclenche lorsqu'un formulaire est soumis.

🎬 Média & Page

  • onplay : Se déclenche lorsque la lecture d'un fichier audio/vidéo commence.
  • onpause : Se déclenche lorsqu'un élément audio/vidéo est mis en pause.
  • onload : Se déclenche lorsque la page est complètement chargée.

💡 oninput réagit immédiatement à chaque caractère saisi, tandis que onchange réagit après la modification (validation ou perte du focus).

🧪 Essayez les événements en direct

Chaque zone ci-dessous utilise réellement l'attribut indiqué : testez-les !

onclick

Aucun clic pour l'instant…

onmouseover / onmouseout

Survolez cette zone

En attente du pointeur…

onfocus / onblur

Cliquez dans le champ pour tester…

oninput

Le miroir apparaît dès la première lettre…

onchange

L'événement se déclenche au changement de sélection…

onkeydown / onkeyup

Pressez puis relâchez une touche…

onsubmit

Le renvoi de la page est bloqué pour la démo…

onload · onplay · onpause

Ces trois événements se placent sur des éléments précis :

exemple.html
<body onload="bienvenue()">

<video onplay="lecture()"
       onpause="arret()">

Ils ne peuvent pas être simulés ici : rechargez la page ou lancez une vidéo pour les déclencher.

10 10. Intégrer une page dans une autre : <iframe>

L'élément <iframe> (inline frame, « cadre en ligne ») permet d'intégrer une page web dans une autre page : vidéo YouTube, carte Google Maps, formulaire externe, document… Le contenu intégré est une page complète, chargée dans un contexte de navigation isolé, comme un écran posé dans la page.

Syntaxe de base
exemple.html
<iframe src="https://exemple.com" width="600" height="400" title="Exemple"></iframe>
Attributs principaux
Attribut Rôle
src URL de la page à afficher.
srcdoc HTML écrit directement dans l'attribut (remplace src).
width / height Dimensions (en pixels ou %).
title Description pour l'accessibilité (recommandé).
name Nom de la frame, utilisable comme cible d'un lien (target).
loading="lazy" Charge l'iframe seulement quand elle devient visible.
sandbox Restreint les droits du contenu intégré (sécurité).
allow Autorise des fonctions (caméra, plein écran, etc.).
allowfullscreen Autorise le mode plein écran.

Exemples utiles

Vidéo YouTube
exemple.html
<iframe width="560" height="315"
        src="https://www.youtube.com/embed/ID_VIDEO"
        title="Vidéo" allowfullscreen></iframe>

Utilisez l'adresse /embed/ID_VIDEO du bouton « Partager → Intégrer », pas l'adresse normale de la vidéo.

Carte Google Maps
exemple.html
<iframe src="https://www.google.com/maps/embed?pb=..."
        width="600" height="450" loading="lazy"
        title="Carte" allowfullscreen></iframe>

Même principe : copiez le code fourni par Google Maps via « Partager → Intégrer une carte ».

Lien qui s'ouvre dans l'iframe
exemple.html
<a href="page2.html" target="cadre">Ouvrir la page 2</a>
<iframe name="cadre" src="page1.html" title="Cadre"></iframe>

Le target du lien porte exactement le name de l'iframe : la page 2 s'affiche dans le cadre, la page principale ne change pas (voir la section 8).

Contenu direct avec srcdoc
exemple.html
<iframe srcdoc="<h1>Bonjour</h1><p>Contenu intégré</p>"></iframe>

Aucun fichier externe : le HTML est écrit dans l'attribut. Les guillemets internes doivent être échappés (&quot;) ou remplacés par des apostrophes.

Iframe responsive (ratio 16:9)
exemple.css
iframe {
  width: 100%;
  aspect-ratio: 16 / 9;
  border: 0;
}

Avec width: 100% et aspect-ratio: 16 / 9, l'iframe garde les bonnes proportions sur mobile comme sur grand écran : plus besoin de fixer width et height en pixels.

border: 0 remplace l'ancien attribut frameborder, aujourd'hui obsolète.

⚠️ À retenir

Sécurité

Une iframe affiche du code que vous ne contrôlez pas : utilisez sandbox pour restreindre les droits du contenu intégré.

exemple.html
<iframe src="page.html" sandbox="allow-scripts"></iframe>
  • sandbox="" (vide) : restrictions maximales, rien n'est autorisé.
  • allow-scripts : autorise le JavaScript du contenu ; allow-forms, allow-popups et allow-modals autorisent formulaires, fenêtres surgissantes et boîtes de dialogue.
  • Évitez de combiner allow-scripts et allow-same-origin pour du contenu non fiable : le cadre pourrait alors sortir de ses restrictions.

Beaucoup de sites interdisent l'intégration via les en-têtes X-Frame-Options ou Content-Security-Policy: frame-ancestors (l'iframe reste alors vide). Pour protéger votre propre site contre le clickjacking, utilisez ces mêmes en-têtes :

en-tetes.txt
X-Frame-Options: DENY
Content-Security-Policy: frame-ancestors 'self'
Bonnes pratiques
  • Toujours ajouter title (accessibilité : les lecteurs d'écran annoncent le contenu du cadre).
  • Ajouter loading="lazy" pour les iframes situées en bas de page (gain de vitesse).
  • Éviter les iframes pour la structure d'un site : préférer des includes PHP ou des composants.
  • Ne pas utiliser frameborder (obsolète) : utiliser border: 0 en CSS.
exemple.html
<!-- 1. Contenu écrit directement : srcdoc -->
<iframe srcdoc="<h1>Bonjour</h1><p>Contenu intégré</p>" title="Démo srcdoc"></iframe>

<!-- 2. Vidéo YouTube en 16:9 responsive -->
<iframe src="https://www.youtube.com/embed/ID_VIDEO"
        title="Vidéo" loading="lazy" allowfullscreen></iframe>

<!-- 3. Lien ouvert dans l'iframe : name + target -->
<a href="page2.html" target="cadre">Ouvrir la page 2</a>
<iframe name="cadre" src="page1.html" title="Cadre"></iframe>

<!-- 4. Page externe (ou carte) intégrée -->
<iframe src="https://exemple.com" title="Site externe" loading="lazy"></iframe>

1. Contenu direct (srcdoc) — fonctionne hors ligne

2. Vidéo YouTube intégrée (cadre 16:9 responsive)

Nécessite une connexion Internet ; ce type d'iframe reste vide si le réseau ou l'intégration sont bloqués.
