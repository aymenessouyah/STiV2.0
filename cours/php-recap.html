PHP : voir l'effet, étape par étape

PHP (PHP: Hypertext Preprocessor) est un langage de programmation de script exécuté côté serveur : le serveur Web (Apache) interprète le code PHP et n'envoie au navigateur que le résultat, sous forme de HTML. Il sert à créer des pages dynamiques, traiter les formulaires et dialoguer avec une base de données (MySQL). Un fichier PHP porte l'extension .php et son code est placé entre <?php et ?>.

Transtypage : conversion de type

Le transtypage consiste à convertir une valeur vers un autre type : entier (int), réel (float), chaîne (string) ou booléen (bool).

Valeur à convertir :
$v = (int) "12.8abc";

Exemples : (int) 12.8 donne 12 ; (float) "12.8" donne 12.8 ; (string) 25 donne "25" ; (bool) "0" donne false. Attention : convertir n'est pas valider une donnée.

Fonctions arithmétiques

abs() — valeur absolue
$n = abs(-15);
echo $n; // 15

Renvoie la distance à zéro : abs(-7.5) donne 7.5.

sqrt() — racine carrée
$n = sqrt(81);
echo $n; // 9

sqrt(2) donne environ 1.4142. Pour une valeur négative, le résultat réel n'est pas défini.

round() — arrondir
round(3.6); // 4
round(3.14159, 2); // 3.14

Le deuxième argument indique le nombre de chiffres après la virgule.

rand() — nombre pseudo-aléatoire

Les deux bornes sont incluses. Pour un tirage sécurisé, utiliser plutôt random_int().

La fonction date() et les formats

En PHP, date() reçoit une chaîne de format. Les lettres sont sensibles à la casse : Y et y n'ont pas le même sens.

echo date("Y-m-d"); // 2026-10-09
echo date("y-m-d"); // 26-10-09
echo date("d-m-Y"); // 09-10-2026
echo date("d/m/Y"); // 09/10/2026
echo date("H:i:s"); // heure:minutes:secondes

mysqli : relier PHP à MySQL (style procédural)

mysqli (« MySQL Improved ») est l'extension de PHP qui fournit les fonctions permettant de communiquer avec un serveur MySQL : se connecter, envoyer des requêtes SQL et lire les résultats.

Ordre habituel d'un script : connexion → choix de la base → requête → lecture du résultat → fermeture. Cliquez sur une fonction pour aller à sa section.

1. mysqli_connect()↑ tableau

mysqli_connect(serveur, utilisateur, mot_de_passe, base) : le 4ᵉ argument (la base) est facultatif, d'où deux formes.

Forme 1 : sans BD (2 instructions)

$cnx = mysqli_connect("localhost", "root", "");
mysqli_select_db($cnx, "lycee");

Forme 2 : avec BD (1 instruction)

$cnx = mysqli_connect("localhost", "root", "", "lycee");

Script PHP

Résultat dans le navigateur

$cnx est l'identifiant de connexion : on le passe en 1er argument de mysqli_select_db, mysqli_query, mysqli_close… Avec la forme 2, une base inexistante fait échouer la connexion elle-même ; avec la forme 1, c'est mysqli_select_db qui renvoie false. (Avec PHP 8.1 et plus, une erreur peut s'afficher sous la forme « Fatal error: Uncaught mysqli_sql_exception » selon la configuration du serveur.)

$cnx = mysqli_connect("localhost", "root", "");

⚠ Attention aux champs AUTO_INCREMENT (ex. id)
  • MySQL attribue lui-même la valeur : ne pas la demander dans le formulaire et ne pas l'imposer dans l'INSERT.
  • Deux écritures correctes : INSERT INTO etudiant (nom, age) VALUES (...) (on ne cite pas id) ou INSERT INTO etudiant VALUES (NULL, ...).
  • Toujours lister les colonnes ou mettre NULL à la place de l'id : sinon MySQL attend une valeur pour chaque colonne, id compris.
  • Imposer un id déjà utilisé provoque l'erreur Duplicate entry.
  • Pour récupérer l'id qui vient d'être généré : mysqli_insert_id($cnx).
  • UPDATE et DELETE : toujours un WHERE, sinon toutes les lignes sont touchées. Un UPDATE renvoie true même si aucune ligne n'est modifiée : true signifie « requête valide », pas « une ligne a changé ».

4. mysqli_num_rows()↑ tableau

mysqli_num_rows($res) renvoie le nombre de lignes d'un résultat de SELECT. On l'utilise pour savoir si la requête a trouvé quelque chose avant d'afficher.

Script PHP

Résultat

Valable uniquement pour un SELECT. Pour un INSERT, un UPDATE ou un DELETE, on utilise mysqli_affected_rows($cnx). Si la requête a échoué ($res vaut false), mysqli_num_rows provoque une erreur : testez d'abord $res.

5. mysqli_fetch_row()↑ tableau

mysqli_fetch_row($res) lit la ligne suivante du résultat et la renvoie sous forme d'un tableau à indices numériques (0, 1, 2…, dans l'ordre des colonnes). À la fin, elle renvoie NULL : c'est ce qui arrête le while.

Script PHP

Ce qui se passe à chaque appel

Accès aux valeurs : $ligne[0], $ligne[1]… Il faut donc connaître l'ordre des colonnes. Toutes les valeurs lues sont des chaînes.

6. mysqli_fetch_array()↑ tableau

mysqli_fetch_array($res) lit la ligne suivante comme mysqli_fetch_row, mais le tableau contient les indices numériques ET les noms des colonnes. Elle renvoie aussi NULL à la fin.

Script PHP

Ce qui se passe à chaque appel

FonctionTableau renvoyéAccès à une valeur
mysqli_fetch_rowindices numériques seulement$ligne[1]
mysqli_fetch_arrayindices numériques et noms des colonnes$ligne[1] ou $ligne['nom']

L'accès par le nom de colonne est plus lisible et ne dépend pas de l'ordre des colonnes. mysqli_fetch_array($res, MYSQLI_ASSOC) ou mysqli_fetch_assoc($res) ne gardent que les noms.

7. mysqli_close()↑ tableau

mysqli_close($cnx);

mysqli_close($cnx) ferme la connexion une fois les requêtes terminées. PHP la ferme de toute façon à la fin du script, mais il est correct de le faire explicitement. Après mysqli_close, $cnx ne doit plus être utilisé.

Exemple complet↑ tableau

<?php
$cnx = mysqli_connect("localhost", "root", "", "lycee");
if (!$cnx) {
    die("Connexion impossible : " . mysqli_connect_error());
}

$nom = $_POST['nom'];
$res = mysqli_query($cnx, "SELECT * FROM etudiant WHERE nom = '$nom'");
if (!$res) {
    die("Erreur SQL : " . mysqli_error($cnx));
}

if (mysqli_num_rows($res) == 0) {
    echo "Aucun étudiant trouvé.";
} else {
    while ($ligne = mysqli_fetch_array($res)) {
        echo $ligne['nom'] . " : " . $ligne['age'] . " ans<br>";
    }
}

mysqli_close($cnx);
?>
