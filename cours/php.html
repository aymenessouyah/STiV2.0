1. Introduction au langage PHP

1.1 Définition

PHP (abréviation de Personal Home Page Hypertext Preprocessor) est un langage de scripts qui s'intègre aux pages HTML et qui permet de réaliser des pages Web dynamiques.

Un langage est dit « côté serveur » lorsque son code est exécuté sur le serveur Web, avant l'envoi de la page au navigateur. Le navigateur ne reçoit jamais le code PHP : il ne reçoit que le résultat, sous forme de HTML « classique ». C'est ce qui distingue PHP d'un langage « côté client » comme JavaScript.

1.2 Le principe client / serveur — en schémas

Analogie n°1 — Le client, le serveur et le chef cuisinier (au restaurant)

Le client ne voit jamais la recette ni la cuisine : il reçoit seulement le plat fini — de même que le navigateur ne reçoit jamais le code PHP, seulement le HTML généré.

Analogie n°2 — Le client au guichet d'une banque

Le client ne voit jamais le système interne — seulement le résultat final, comme l'internaute ne reçoit que la page HTML finale.

1.3 Syntaxe générale d'un script PHP

<?php
   // instructions PHP ici
   echo "Bonjour tout le monde !";
?>

Chaque instruction se termine par ;, les commentaires s'écrivent avec // ou /* ... */.

6. Fonctions de date et d'heure

Un timestamp est un entier long contenant le nombre de secondes écoulées entre le début de l'époque UNIX (1ᵉʳ janvier 1970 à 00:00:00 GMT) et une date donnée. Sur un site dynamique, on est souvent amené à : affecter la date/l'heure système à une variable, ajouter une période à une date, changer le format d'affichage d'une date, ou traiter des champs de type date.

Fonction Rôle (annexe)
checkdate() Vérifie la validité d'une date
date() Formate une date et la retourne sous forme de chaîne
time() Retourne l'heure actuelle en nombre de secondes
strtotime() Transforme une chaîne contenant une date en timestamp

6.1 checkdate — vérifier une date

Syntaxe : int checkdate(int m, int j, int a)

Retourne TRUE si la date représentée par le jour j, le mois m et l'année a est valide, sinon FALSE. Attention : l'ordre des arguments n'est pas l'ordre français (mois, jour, année). La date est valide si l'année est comprise entre 1 et 32767, le mois entre 1 et 12, et le jour dans l'intervalle du mois — les années bissextiles sont prises en compte. 

<?Php
$j=24; $m=9; $a=2026;
if (checkdate($m,$j,$a)==true) $d=$j."/".$m."/".$a;
else $d="données invalide ";
echo($d);
?>

6.2 date — formater une date

Syntaxe : string date(string format, [int timestamp])

Retourne une date sous forme de chaîne, au format donné par le paramètre format (ex. Y = année, m = mois, d = jour, H = heures, i = minutes, s = secondes). La date utilisée est celle du timestamp fourni, ou la date/heure courantes si aucun timestamp n'est fourni. 

<?Php
$d=date("Y-m-d H:i:s");
echo("Nous sommes le : ".$d);
?>

6.3 getdate — informations détaillées sur une date

Syntaxe : array getdate([int timestamp])

Retourne un tableau associatif contenant les informations de date et d'heure du timestamp fourni (ou de la date/heure courante sinon). Le tableau comporte les éléments : seconds, minutes, hours, mday, wday, mon, year, yday, weekday, month. 

<?php
$a=getdate();
$b=date("d-m-Y H:i:s");
echo("Nous sommes le : ".$b."<br>");
echo("Les secondes : ".$a["seconds"]."<br>");
echo("Les minutes : ".$a["minutes"]."<br>");
echo("Les heures : ".$a["hours"]."<br>");
echo("Le jour du mois : ".$a["mday"]."<br>");
echo("Le jour de la semaine : ".$a["wday"]."<br>");
echo("Les mois : ".$a["mon"]."<br>");
echo("L'année : ".$a["year"]."<br>");
echo("Le jour de l'année : ".$a["yday"]."<br>");
echo("Le nom du jour de la semaine : ".$a["weekday"]."<br>");
echo("Le nom du mois : ".$a["month"]."<br>");
?>

6.4 time — timestamp de l'instant présent

<?Php
$a=time();
$b=date("d/m/Y H:i:s",$a);

6.5 mktime — construire un timestamp

Syntaxe : int mktime(int hour, int min, int sec, int month, int day, int year, int is_dst)

Retourne un timestamp correspondant aux arguments fournis. Les arguments peuvent être omis de droite à gauche ; tout argument manquant prend la valeur courante de l'heure ou du jour. is_dst vaut 1 si l'heure d'été est appliquée, 0 sinon, et -1 (par défaut) si on ne sait pas. 

<?Php
$h=10; $mn=30; $s=0; $m=9; $j=24; $a=2026;
$ns=mktime($h,$mn,$s,$m,$j,$a);
echo("le nombre de secondes est : ".$ns."<br>");
$d=date("d-m-Y H:i:s",$ns);
echo("Ce nombre de secondes correspond à la date : ".$d);
?>

6.6 strtotime — interpréter une date en format anglais

Syntaxe : int strtotime(string time, [int now])

Essaie de lire une date au format anglais et de la transformer en timestamp, relativement au timestamp now, ou à la date courante si celui-ci est omis. Accepte aussi des expressions relatives comme "+1 day", "+1 week".

8.1 Le circuit d'une requête, étape par étape

1. Connexion — mysqli_connect(hôte, utilisateur, mot_de_passe) ouvre une connexion au serveur MySQL et retourne une ressource de connexion (ex. $connexion).
2. Sélection de la base — mysqli_select_db($connexion, "nom_bd") indique sur quelle base travailler.
3. Construction de la requête SQL — la requête (SELECT, INSERT, UPDATE, DELETE…) est écrite dans une chaîne PHP, avec les valeurs des variables insérées.
4. Exécution — mysqli_query($connexion, $requete) envoie la requête au serveur ; elle retourne un résultat (SELECT) ou true/false (INSERT/UPDATE/DELETE).
5. Exploitation du résultat — pour un SELECT, on parcourt les lignes avec mysqli_fetch_array() dans une boucle while.
6. Fermeture — mysqli_close($connexion) libère la connexion en fin de script.

8.2 Fonctions MySQLi essentielles

Fonction Rôle Type de retour
mysqli_connect(host,user,pass) Connexion au serveur MySQL object mysqli (ressource de connexion), ou false en cas d'échec
mysqli_select_db(cnx,bd) Sélectionne la base bool
mysqli_query(cnx,req) Envoie et exécute une requête SQL object mysqli_result pour un SELECT ; bool (true/false) pour INSERT/UPDATE/DELETE
mysqli_fetch_array(res) Ligne en tableau associatif + numérique array, ou null s'il n'y a plus de ligne
mysqli_fetch_row(res) Ligne en tableau indexé numériquement array indexé, ou null s'il n'y a plus de ligne
mysqli_num_rows(res) Nombre de lignes du résultat int
mysqli_affected_rows(cnx) Lignes affectées (INSERT/UPDATE/DELETE) int
mysqli_insert_id(cnx) Dernier id AUTO_INCREMENT généré int
mysqli_error(cnx) Dernier message d'erreur string
mysqli_close(cnx) Ferme la connexion bool

8.3 mysqli_query() : un comportement différent selon la requête

Syntaxe : mixed mysqli_query(mysqli $connexion, string $requete). Cette fonction envoie n'importe quelle requête SQL au serveur, mais ce qu'elle retourne dépend du type de requête :

Pour un SELECT (ou SHOW, DESCRIBE…) — elle retourne un objet mysqli_result : un « résultat » qu'il faut ensuite parcourir avec mysqli_fetch_array() ou mysqli_fetch_row(). En cas d'erreur de syntaxe SQL, elle retourne false.
Pour un INSERT / UPDATE / DELETE — il n'y a pas de lignes à lire : elle retourne simplement true (succès) ou false (échec). On connaît alors l'effet de la requête via mysqli_affected_rows() ou mysqli_insert_id(), jamais via mysqli_fetch_array(). 
<?php
// SELECT : mysqli_query retourne un résultat à parcourir
$res = mysqli_query($connexion, "SELECT nom FROM eleves");
if ($res) {
   while ($ligne = mysqli_fetch_array($res)) {
      echo $ligne["nom"] . "<br>";
   }
} else {
   echo "Erreur SQL : " . mysqli_error($connexion);
}

// INSERT : mysqli_query retourne true / false
$ok = mysqli_query($connexion, "INSERT INTO eleves (nom) VALUES ('Sami')");
if ($ok) {
   echo "Insertion réussie, id = " . mysqli_insert_id($connexion);
} else {
   echo "Erreur SQL : " . mysqli_error($connexion);
}

// UPDATE : mysqli_query retourne aussi true / false
$ok2 = mysqli_query($connexion, "UPDATE eleves SET moyenne = 16 WHERE nom = 'Sami'");
if ($ok2) {
   echo mysqli_affected_rows($connexion) . " ligne(s) mise(s) à jour.";
}
?>

8.4 mysqli_fetch_array() et mysqli_fetch_row()

mysqli_fetch_array($resultat) extrait la ligne courante du résultat et avance automatiquement au suivant à chaque appel ; par défaut elle retourne un tableau à la fois associatif et numérique (indices texte et indices entiers pour la même valeur), tant qu'il reste des lignes, sinon null.

mysqli_fetch_row($resultat) fait la même chose mais retourne uniquement un tableau indexé numériquement (comme un tableau classique 0, 1, 2…), sans les clés textuelles. 

<?php
$res = mysqli_query($connexion, "SELECT nom, moyenne FROM eleves");

// Avec mysqli_fetch_array : accès par nom de colonne OU par indice
$ligne = mysqli_fetch_array($res);
echo $ligne["nom"];      // accès associatif : "Ali"
echo $ligne[0];           // accès numérique : "Ali" (même valeur)
echo $ligne["moyenne"];   // "14.5"
echo $ligne[1];           // "14.5"

// Avec mysqli_fetch_row : accès uniquement par indice numérique
$res2 = mysqli_query($connexion, "SELECT nom, moyenne FROM eleves");
while ($row = mysqli_fetch_row($res2)) {
   echo $row[0] . " a pour moyenne " . $row[1] . "<br>";
   // $row["nom"] n'existerait pas ici : uniquement $row[0], $row[1]...
}
?>

En pratique, mysqli_fetch_array() est le plus utilisé en classe car $ligne["colonne"] rend le code plus lisible ; mysqli_fetch_row() est plus léger quand on connaît déjà l'ordre exact des colonnes.

8.5 mysqli_num_rows()

Syntaxe : int mysqli_num_rows(mysqli_result $resultat). Elle retourne le nombre de lignes contenues dans un résultat de type SELECT. Elle ne s'applique qu'à un résultat de SELECT (un objet mysqli_result) — pour connaître le nombre de lignes touchées par un INSERT/UPDATE/DELETE, on utilise mysqli_affected_rows() à la place. 

<?php
$req = "SELECT * FROM eleves WHERE moyenne >= 10";
$resultat = mysqli_query($connexion, $req);
$nb = mysqli_num_rows($resultat);

if ($nb == 0) {
   echo "Aucun élève admis.";
} else {
   echo $nb . " élève(s) admis :<br>";
   while ($ligne = mysqli_fetch_array($resultat)) {
      echo "- " . $ligne["nom"] . "<br>";
   }
}
?>

<?php

Sécurité : toujours contrôler/échapper les données saisies par l'utilisateur avant de les insérer dans une requête SQL, afin d'éviter les injections SQL. Les anciennes fonctions mysql_* (sans « i ») sont obsolètes : utiliser MySQLi.

    • ease-in : démarrage lent, puis accélération jusqu'à la fin ;
    • ease-out : démarrage rapide, puis ralentissement en douceur à la fin ;
    • ease-in-out : lent au début et à la fin, rapide au milieu — l'effet le plus doux.
    Utilisez au moins deux de ces fonctions dans votre style.css (par exemple ease-out pour les liens de la navigation et ease-in-out avec all pour les champs).

// ===== validation.js : contrôler la saisie avant l'envoi =====
// Variables déclarées avec let ; messages avec innerHTML et alert()

function afficherErreur(texte) {
   let message = document.getElementById("message");
   message.innerHTML = texte; // message affiché dans la page
   alert(texte);              // ... et dans une boîte de dialogue
   return false;              // l'envoi du formulaire est annulé
}

function commenceParMajuscule(texte) {
   return texte.length > 0 && texte[0] >= "A" && texte[0] <= "Z";
}

function dateDansLePasse(valeur) {
   if (valeur == "") return false;
   let saisie = new Date(valeur);
   let aujourdHui = new Date();
   return saisie <= aujourdHui;
}

// Éliminer les espaces superflus : au début, à la fin,
// et plusieurs espaces de suite remplacés par un seul
function nettoyerNomPrenom(valeur) {
   return valeur.trim().replace(/\s+/g, " ");
}

// Nom_prenom correct : uniquement des lettres (accentuées acceptées)
// et des espaces, avec un nombre de mots entre 2 et 5
function nomPrenomCorrect(valeur) {
   let lettresEtEspaces = /^[A-Za-zÀ-ÖØ-öø-ÿ ]+$/;
   if (!lettresEtEspaces.test(valeur)) return false;
   let mots = valeur.split(" ");
   return mots.length >= 2 && mots.length <= 5;
}

// Contrôles communs : Id, Moyenne, DateNaissance
function controlesCommuns() {
   let Id = document.getElementById("Id").value;
   let Moyenne = document.getElementById("Moyenne").value;
   let DateNaissance = document.getElementById("DateNaissance").value;
   let message = document.getElementById("message");

   if (!commenceParMajuscule(Id)) {
      return afficherErreur("Erreur : l'Id doit commencer par une lettre en majuscule.");
   }
   if (Moyenne == "" || isNaN(Moyenne) || Moyenne < 0 || Moyenne > 20) {
      return afficherErreur("Erreur : la Moyenne doit être un nombre entre 0 et 20.");
   }
   if (!dateDansLePasse(DateNaissance)) {
      return afficherErreur("Erreur : la Date de naissance doit être remplie et ne pas être dans le futur.");
   }
   message.innerHTML = "";
   return true;
}

// Page inscription.html : on contrôle aussi le Nom_prenom
function validerInscription() {
   let champNom = document.getElementById("Nom_prenom");
   let NomPrenom = nettoyerNomPrenom(champNom.value);
   champNom.value = NomPrenom; // c'est le nom nettoyé qui sera envoyé

      return afficherErreur("Erreur : le Nom et le Prénom ne doivent contenir que des lettres et des espaces, avec 2 à 5 mots (ex. Benali Amine).");
   }
   return controlesCommuns();
}

// L'heure actuelle s'affiche dès l'entrée dans la page, et se met à jour chaque seconde
function afficherHeure() {
   let zone = document.getElementById("horloge");
   if (!zone) return; // la page modifier.php n'a pas d'horloge
   let maintenant = new Date();
   let h = maintenant.getHours();
   let m = maintenant.getMinutes();
   let s = maintenant.getSeconds();
   let texte = "🕐 Heure actuelle : "
      + (h < 10 ? "0" + h : h) + ":"
      + (m < 10 ? "0" + m : m) + ":"
      + (s < 10 ? "0" + s : s);
   let minutes = h * 60 + m;
   if ((minutes >= 480 && minutes < 720) || (minutes >= 780 && minutes < 1080)) {
      texte += " — ✅ Station ouverte (horaires : 8h00-12h00 et 13h00-18h00)";
   } else {
      texte += " — 🔴 Station fermée (horaires : 8h00-12h00 et 13h00-18h00)";
   }
   zone.innerHTML = texte;
}

// L'heure de recharge est-elle dans les horaires de travail ?
// Retourne un booléen : true si 8h00 <= heure < 12h00 ou 13h00 <= heure < 18h00
function heureDansHoraires(heure) {
   if (heure == "") return false;
   let parties = heure.split(":");
   let minutes = parseInt(parties[0]) * 60 + parseInt(parties[1]);
   return (minutes >= 480 && minutes < 720) || (minutes >= 780 && minutes < 1080);
}

// Éliminer les espaces superflus : au début, à la fin,

function nettoyerNomPrenom(valeur) {
   return valeur.trim().replace(/\s+/g, " ");

// Nom_prenom correct : uniquement des lettres (accentuées acceptées)
// et des espaces, avec un nombre de mots entre 2 et 5
function nomPrenomCorrect(valeur) {
   let lettresEtEspaces = /^[A-Za-zÀ-ÖØ-öø-ÿ ]+$/;
   if (!lettresEtEspaces.test(valeur)) return false;
   let mots = valeur.split(" ");
   return mots.length >= 2 && mots.length <= 5;
}

// Contrôles communs : Id, Kwh, DateRecharge
function controlesCommuns() {
   let Id = document.getElementById("Id").value;
   let Kwh = document.getElementById("Kwh").value;
   let DateRecharge = document.getElementById("DateRecharge").value;
   let HeureRecharge = document.getElementById("HeureRecharge").value;
   let message = document.getElementById("message");

   if (!commenceParMajuscule(Id)) {
      return afficherErreur("Erreur : l'Id doit commencer par une lettre en majuscule.");
   }
   if (Kwh == "" || isNaN(Kwh) || Kwh < 1 || Kwh > 100) {
      return afficherErreur("Erreur : l'énergie Kwh doit être un nombre entre 1 et 100.");
   }
   if (!dateDansLePasse(DateRecharge)) {
      return afficherErreur("Erreur : la Date de la recharge doit être remplie et ne pas être dans le futur.");
   }
   if (!heureDansHoraires(HeureRecharge)) {
      return afficherErreur("Erreur : fixez l'heure de la recharge dans les horaires de travail (8h00-12h00 ou 13h00-18h00).");
   }
   message.innerHTML = "";
   return true;
}
