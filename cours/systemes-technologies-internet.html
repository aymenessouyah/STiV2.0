Une vision globale du domaine

Un ordinateur, un téléphone, une montre connectée ou une caméra intelligente sont des équipements informatiques. Pour fonctionner et communiquer, ils utilisent des logiciels, des réseaux et des protocoles.

💻Le système

Gère les ressources matérielles et permet d’exécuter les applications.

🌐Le réseau

Permet aux équipements d’échanger des données et de partager des ressources.

📡L’IoT

Connecte des objets physiques capables de transmettre et de recevoir des données.

Situation de départ.

Un élève utilise son ordinateur pour consulter un cours, son téléphone pour envoyer un message et une montre connectée pour suivre son activité. Qui permet à ces équipements de fonctionner ? Comment communiquent-ils ? Comment les données arrivent-elles sur Internet ?

01 Les systèmes d’exploitation

Gérer l’environnement de travail

1.1 Définition

Un ordinateur est composé de matériels (Hardware) et de logiciels (Software). Le matériel comprend notamment l’écran, le clavier, la souris, le processeur, la mémoire vive et le disque. Le logiciel regroupe les programmes utilisés par l’utilisateur.

👤 Utilisateurtravaille avec des applications
↕
⚙️ Système d’exploitationlogiciel de base
↕
🖥️ Matérielprocesseur, mémoire, disque, périphériques

Définition : le système d’exploitation est un logiciel de base qui assure la gestion du matériel et permet l’exécution des applications.

1.2 Les rôles d’un système d’exploitation

Les six rôles à connaître
RôleExplicationExemple
Gérer le processeurOrganiser l’exécution des programmes.Navigateur et lecteur vidéo ouverts simultanément.
Gérer la mémoireRépartir la mémoire entre les applications.Ouvrir plusieurs logiciels.
Gérer les fichiersCréer, supprimer, déplacer et organiser les fichiers.Créer un dossier.
Gérer les périphériquesCommuniquer avec les équipements.Imprimante, clavier.
Gérer les utilisateursContrôler les comptes et les autorisations.Compte administrateur.
Assurer la sécuritéProtéger le système et les données.Pare-feu et mises à jour.

1.3 Les types de systèmes d’exploitation

🖥️Pour PC

Windows : système propriétaire de Microsoft.
Linux : famille de systèmes libres, avec plusieurs distributions comme Ubuntu.
macOS : système des ordinateurs Mac d’Apple.

📱Pour mobiles

Android : utilisé sur de nombreux smartphones et tablettes.
iOS : système d’exploitation des iPhone.

⌚Embarqués

watchOS : montres Apple.
tvOS : appareils Apple TV.
QNX : systèmes embarqués, notamment dans l’automobile.

📌 À retenir.

Un système embarqué est intégré dans un appareil spécialisé qui réalise des fonctions précises.

02 Les réseaux informatiques

Assurer la communication

2.1 Définition

Un réseau informatique est un ensemble d’équipements informatiques reliés entre eux afin d’échanger des données et de partager des ressources.

💻 PC 1poste de travail
💻 PC 2poste de travail
🖨️ Imprimanteressource partagée
🗄️ Serveurservices et fichiers
↕
🔀 Switch / Routeurrelie les équipements

2.2 Classification selon l’étendue

LAN, MAN et WAN
TypeÉtendueExemple
LANLocaleRéseau d’un lycée ou d’une salle informatique.
MANVille ou zone métropolitaineRéseau reliant plusieurs établissements d’une ville.
WANTrès grande zoneRéseau reliant des sites dans plusieurs pays.

2.3 Les équipements d’un réseau

Qui fait quoi dans le réseau
ÉquipementFonction
Carte réseauPermet à un appareil de se connecter à un réseau.
Switch (commutateur)Relie plusieurs appareils dans un réseau local.
RouteurRelie différents réseaux et dirige les paquets.
Point d’accès Wi-FiPermet une connexion sans fil.
ServeurFournit des services ou des ressources aux clients.

2.4 Les paramètres d’un composant réseau

A. Adresse IP

L’adresse IP identifie une interface réseau dans un réseau utilisant le protocole IP. Exemple IPv4 : 192.168.1.20. Une adresse IPv4 est composée de quatre nombres compris entre 0 et 255, séparés par des points.

B. Masque réseau

Le masque permet de déterminer la partie réseau et la partie hôte d’une adresse IPv4. Exemple : adresse IP 192.168.1.20 et masque 255.255.255.0 ; l’adresse réseau correspondante est 192.168.1.0.

C. Serveur DNS

DNS signifie Domain Name System. Il permet de traduire un nom de domaine en adresse IP. Exemple : le navigateur demande la résolution de www.example.com.

D. Adresse MAC

L’adresse MAC est associée à une interface réseau. Exemple de format : A4-B1-C1-2D-3E-4F. Elle est notamment utilisée pour identifier une interface dans un réseau local.

Les quatre paramètres, en résumé
ParamètreRôle
Adresse IPIdentifier une interface au niveau IP.
Masque réseauDéterminer le réseau et la partie hôte.
DNSRésoudre un nom de domaine en adresse IP.
MACIdentifier une interface au niveau de la liaison locale.

2.5 Les architectures des réseaux

Client / serveur

Un ordinateur client demande un service à un ordinateur serveur.

Client 1demande
Client 2demande
Client 3demande
↕
🗄️ Serveurfournit le service

Avantages : centralisation des données, gestion des utilisateurs et administration centralisée.
Inconvénient : si le serveur tombe en panne, les services qu’il fournit peuvent devenir indisponibles.

Poste à poste (Peer-to-Peer)

Les ordinateurs communiquent directement entre eux et peuvent partager des ressources sans serveur central obligatoire.

PC 1
PC 2
PC 3
↔
Communication directesans serveur central

Avantages : partage direct et organisation simple pour un petit réseau.
Inconvénients : gestion moins centralisée, sécurité et sauvegarde plus difficiles à administrer.

2.6 Les protocoles de communication

Un protocole est un ensemble de règles qui permet aux équipements de communiquer.

Les protocoles du programme
ProtocoleSignification / rôleUsage
TCP/IPSuite de protocoles de communication sur les réseaux.IP assure l’adressage et l’acheminement ; TCP assure une transmission fiable et ordonnée.
HTTPHyperText Transfer Protocol.Échange de ressources entre un client et un serveur Web.
HTTPSVersion sécurisée de HTTP utilisant TLS.Échange Web protégé, avec chiffrement et authentification du serveur.
MQTTMessage Queuing Telemetry Transport.Messagerie légère, particulièrement adaptée aux objets connectés.

Pare-feu (Firewall) : contrôle les communications réseau selon des règles de sécurité.
Liste de contrôle d’accès (ACL) : contient des règles qui autorisent ou interdisent certains accès ou certaines communications.

03 L’Internet des objets (IoT)

Connecter des objets physiques

3.1 Définition

L’Internet des objets, appelé IoT (Internet of Things), désigne l’ensemble des objets physiques capables de collecter, transmettre et échanger des données grâce à une connexion réseau.

🏠Maison

Éclairage et thermostat connectés.

🌱Agriculture

Capteur d’humidité du sol.

🏥Santé

Appareil de suivi connecté.

🏭Industrie

Capteur de température.

🚦Ville

Gestion de l’éclairage public.

🚗Transport

Suivi de véhicules.

3.2 Les composants fondamentaux

  • Objet connecté : équipement qui collecte ou utilise les données.
  • Capteur : élément qui mesure une grandeur.
  • Connexion réseau : permet de transmettre les données.
  • Serveur ou plateforme IoT : reçoit et stocke les données.
  • Application : affiche les informations ou permet de commander l’objet.

3.3 Principe général de fonctionnement

🌡️ Capteurmesure 25 °C
→
🔌 Objet connectéprépare la donnée
→
📶 RéseauHTTP / MQTT
→
☁️ Plateformereçoit la donnée
→
📱 Utilisateurconsulte

Exemple : suivi de température. Le capteur mesure la température ; l’objet connecté récupère la mesure ; il transmet la valeur à une plateforme distante ; l’utilisateur consulte la température sur son téléphone.

3.4 Échanger des données avec une plateforme IoT

Pour communiquer avec une plateforme distante, l’objet connecté doit :

  1. être configuré pour accéder au réseau ;
  2. disposer des informations nécessaires à la communication ;
  3. utiliser un protocole adapté ;
  4. envoyer ou recevoir des données ;
  5. tester le programme et corriger les erreurs.
Communication avec HTTP

HTTP permet à l’objet connecté d’envoyer une requête à un serveur.

Communication avec MQTT

MQTT permet l’échange de messages via un broker.
Publisher : publie un message.
Broker : reçoit et distribue les messages.
Subscriber : reçoit les messages auxquels il s’est abonné.

Exemple de sujet : maison/salon/temperature.

3.5 Tester et corriger un programme IoT

Du symptôme à la vérification
Problème observéVérification à effectuer
Pas de connexionVérifier le Wi-Fi et la configuration réseau.
Le serveur ne répond pasVérifier l’adresse du serveur et son accessibilité.
Aucune donnée reçueVérifier la requête HTTP ou le message MQTT.
Mauvaise valeur affichéeVérifier la mesure et le format transmis.

Une serre agricole est équipée d’un capteur d’humidité du sol. Les mesures sont envoyées à une plateforme IoT. L’agriculteur consulte les valeurs depuis son téléphone.

10 Évaluation générale

/ 10 points

Vérifier les notions essentielles des trois chapitres. Consigne : répondre brièvement et justifier lorsque cela est demandé.

A. Systèmes d’exploitation

  1. Définir un système d’exploitation et citer deux de ses rôles.
  2. Classer Windows et Linux selon le type de licence. Expliquer la différence.
  3. À quoi sert une machine virtuelle ? Donner un exemple de logiciel de virtualisation.

B. Réseaux informatiques

  1. Donner la signification de LAN, MAN et WAN, puis citer un exemple pour l’un d’eux.
  2. Associer chaque paramètre à son rôle : adresse IP, masque, DNS et adresse MAC.
  3. Expliquer la différence entre un switch et un routeur.
  4. Comparer les architectures client/serveur et poste à poste.

C. Internet des objets

  1. Définir l’Internet des objets (IoT) et donner un exemple d’utilisation.
  2. Citer quatre composants d’une solution IoT et préciser le rôle d’un capteur.
  3. Décrire le trajet d’une mesure depuis un capteur jusqu’à son affichage sur une plateforme.
🔎 Afficher les repères de correction
  1. Logiciel de base qui gère le matériel et permet l’exécution des applications — par exemple gérer la mémoire et les fichiers.
  2. Windows : propriétaire (licence qui définit les droits, code source non librement accessible). Linux : libre (libertés d’utilisation, d’étude, de modification et de redistribution).
  3. Elle permet d’installer et d’utiliser un autre système dans une fenêtre, sans remplacer le système principal — VMware ou VirtualBox.
  4. LAN : local (salle informatique) ; MAN : une ville ; WAN : plusieurs pays.
  5. IP : identifier une interface ; masque : séparer réseau et hôte ; DNS : traduire un nom en adresse IP ; MAC : identifier une interface localement.
  6. Le switch relie des appareils d’un même réseau local ; le routeur relie des réseaux différents et dirige les paquets.
  7. Client/serveur : services centralisés, panne du serveur = services indisponibles ; poste à poste : partage direct, plus simple, mais sécurité et sauvegarde moins centralisées.
  8. Objets physiques capables de collecter, transmettre et échanger des données — par exemple un capteur d’humidité dans une serre.
  9. Objet connecté, capteur, connexion réseau, plateforme IoT, application ; le capteur mesure une grandeur.
  10. Le capteur mesure ; l’objet récupère et transmet la valeur (HTTP ou MQTT) ; la plateforme la reçoit et la stocke ; l’utilisateur la consulte depuis son téléphone.
