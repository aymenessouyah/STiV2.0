Les fiches sont regroupées dans une nouvelle famille « Fiches méthode », après les travaux pratiques et avant les annexes. Il ne s’agit pas d’une nouvelle série d’exercices.

### Méthode de résolution
- Analyser l’énoncé, identifier entrées et sorties, décomposer, réaliser et vérifier.
- 3SI : rôles HTML/CSS/JavaScript et méthode de préparation d’un SELECT sur une seule table.
- 4SI : cycle navigateur → formulaire → PHP → MySQL → réponse, et répartition des contrôles client/serveur.
- Un petit programme de cumul est accompagné d’un tableau de trace montrant les indices et les valeurs successives.

### Erreurs fréquentes
- Tableau HTML, CSS, JavaScript et SQL adapté au niveau.
- 4SI : contrôles côté PHP et distinction entre sélection vide et échec de requête.
- Méthode : localiser, corriger une cause, vérifier à nouveau et éviter les régressions.

### Tests et vérification
- Modèle entrée / résultat attendu / résultat obtenu pour une note de 0 à 20.
- Cas normaux, limites, absence et données incorrectes ; tableau vide et sélection sans ligne.
- Prudence avant modification d’une base et checklist de remise.
- 4SI : rappels sur les contrôles serveur et les limites de sécurité des exemples pédagogiques.
