Éléments de
1er niveau		html Représente la racine d'un document HTML. Tout autre élément du
document doit être un descendant de cet élément.
head L'élément HTML <head> fournit des informations générales
(métadonnées) sur le document, incluant son titre et des liens ou des
définitions vers des scripts et feuilles de style.
body La balise <body> est une balise HTML permettant d'indiquer au
navigateur où commence votre corps de page et où il se termine.
Éléments d’entêtelink L'élément HTML <link> définit la relation entre le document courant et
une ressource externe. Cet élément peut être utilisé pour définir un lien
vers une feuille de style, vers les icônes utilisées en barre de titre ou
comme icône d'application sur les appareils mobiles.
Attributs :
- href : Cet attribut définit l'URL de la ressource liée. L'URL utilisée
peut être absolue ou relative.
- rel: Cet attribut indique la relation qui existe entre le document et la
ressource liée. Cet attribut doit être une liste de types de lien,
séparés par des espaces.
- type : Cet attribut est utilisé pour définir le type de contenu auquel
le lien fait référence. Dans notre cas on utilise text/css		<html lang="fr">

meta L'élément HTML <meta> représente toute information de métadonnées
qui ne peut pas être représentée par un des autres éléments de
métadonnées (<base>, <link>, <script>, <style> ou <title>).		</head>
script L'élément HTML <script> est utilisé pour intégrer ou faire référence à un script
exécutable. Cela fait généralement référence à du code JavaScript mais ce
peut également être un autre type de script
Attributs :
-
src : Cet attribut définit l'URI d'un script externe. Cela peut être
utilisé pour insérer des scripts autrement qu'en les insérant à même
le document. Les éléments script avec un attribut src défini ne doivent
pas avoir de script compris dans leurs balises. Cela peut causer un
comportement inattendu où le contenu du fichier référencé est
chargé mais où le contenu de l'élément est ignoré.
-
type : Cet attribut indique le type de script. La valeur de cet attribut
peut appartenir à plusieurs catégories.		<script src="controles.js"></script>
style Définit les informations de style (CSS) pour un document. Attributs : type, media
title Définit le titre du document.
