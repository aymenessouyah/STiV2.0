⚖ fetch_row / fetch_array / fetch_assoc

FonctionAccès
fetch_rowindexé : $l[0], $l[1]
fetch_arraymixte : $l[0] ou $l["Id"] (valeurs en double)
fetch_assocassociatif : $l["Id"] (le plus lisible)

Les 3 renvoient null quand il n'y a plus de ligne → fin du while.

🔢 Qui compte les lignes ?

MéthodeQuand ?
mysqli_num_rows() (PHP)Après un SELECT dont on affiche aussi les lignes (liste.php)
SELECT COUNT(*) AS nb (SQL)Juste le nombre : 1 seule valeur revient (statistiques)

COUNT(*) compte côté serveur ; AVG(), MAX() idem.

🎨 CSS & 🟨 JavaScript — rappels

NotionÀ retenir
floatSort du flux : flotter l'élément et ses frères (ou margin-left) pour rester dans le même couloir ; footer : div .milieu avant, ou div clear: both après la section.
transition: propriété durée fonction délai;all = tout animer · ease lent-rapide-lent (défaut) · ease-in démarre lent · ease-out finit doux · ease-in-out lent aux deux bouts.
onsubmit="return f()"Le return est indispensable : sans lui, le false ne bloque pas l'envoi. Messages : innerHTML et/ou alert() ; variables en let.
Nom_prenomNettoyer les espaces superflus (trim + espaces multiples → 1), lettres et espaces uniquement, 2 à 5 mots (split).
Dates JSMois de 0 à 11 ! getDate() jour, getMonth() mois−1, getFullYear() année. Une fonction de contrôle retourne un booléen.
Web localDossier sous www/htdocs, appel par http://localhost/dossier/ ; s'il existe, index s'affiche seul.
💡 Piège n°1 : mysqli_query qui retourne true après un UPDATE ne prouve pas la modification → vérifier avec mysqli_affected_rows() > 0.  ·  Piège n°2 : utiliser mysqli_num_rows après un UPDATE → utiliser mysqli_affected_rows.
