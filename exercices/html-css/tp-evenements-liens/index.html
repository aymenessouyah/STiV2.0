2. Les pseudo-classes des liens

Récapitulatif (respecter l'ordre L, V, H, A)
SélecteurÉtat du lienCouleur utilisée ici
a:linkLien non encore visitéBleu #1f4e79
a:visitedLien déjà visitéViolet #8e44ad
a:hoverSouris au-dessus du lienOrange #e67e22, souligné
a:activeLien en cours de clicRouge #c0392b, fond jaune pâle
  • Lien non visité (a:link) : survolez-le, puis cliquez sans relâcher (a:hover, a:active)
  • Lien déjà visité (a:visited) : il pointe vers cette page, que vous avez forcément visitée

Pour des raisons de confidentialité, le navigateur n'autorise sur a:visited que les propriétés de couleur.

3. Les propriétés d'arrière-plan (image du drapeau)

Récapitulatif
PropriétéRôleValeurs courantes
background-colorCouleur de fond (visible aussi sous une image transparente)nom, #hex, rgb(), rgba()
background-imageImage de fondurl('drapeau.png'), none
background-repeatRépétition de l'image (par défaut : repeat)repeat, repeat-x, repeat-y, no-repeat, space, round
background-sizeTaille de l'imageauto, cover, contain, 100px 60px, 50%
backgroundPropriété raccourcie : regroupe les précédentescouleur image repeat position / taille

background-color et background-image

background-color: #e67e22;
background-image: url('drapeau.png');
(taille réelle : l'image dépasse la boîte)

background-repeat (image réduite à 60px pour voir la répétition)

background-repeat: repeat;
background-repeat: repeat-x;
background-repeat: repeat-y;
background-repeat: no-repeat;
background-repeat: space;
(espaces égaux, sans rognage)
background-repeat: round;
(image redimensionnée pour remplir)

background-size

background-size: cover;
(remplit la boîte, rogne)
background-size: contain;
(image entière visible)
background-size: 100px 60px;
background-size: 50%;

La propriété raccourcie background

background: #1f4e79 url('drapeau.png') no-repeat center / 70%;

Le bandeau en haut de la page utilise aussi le raccourci : background: url('drapeau.png') no-repeat center / cover;
