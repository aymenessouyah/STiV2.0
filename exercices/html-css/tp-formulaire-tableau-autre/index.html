3. figure, figcaption et video

Récapitulatif
Balise / attribut Rôle
<figure> Conteneur sémantique d'un contenu illustratif (image, vidéo, code, tableau) lié au texte
<figcaption> Légende de la figure ; doit être le premier ou le dernier enfant de <figure>
<video> Intègre une vidéo dans la page
src Chemin ou URL du fichier vidéo (.mp4, .webm, .ogg)
controls Affiche les commandes du lecteur (lecture, pause, volume, plein écran) ; sans lui, aucune commande n'apparaît

4. cite, address, output, mark, details, summary, hidden, fieldset, legend

Récapitulatif
Balise / attribut Rôle
<cite> Titre d'une œuvre citée (livre, film, article) ; affiché en italique
<address> Coordonnées de l'auteur ou du responsable de la page ; affiché en italique
<output> Affiche le résultat d'un calcul ; attribut for = liste des id des champs sources
<mark> Surligne un texte pertinent (fond jaune par défaut)
<details> Bloc que l'on déplie ou replie ; attribut open pour l'afficher déplié
<summary> Titre cliquable de <details> (premier enfant)
hidden Attribut qui cache l'élément (comme display:none) ; input type="hidden" envoie une valeur sans l'afficher
<fieldset> Regroupe des champs d'un formulaire ; attribut disabled désactive tout le groupe
<legend> Titre du <fieldset> (premier enfant)
