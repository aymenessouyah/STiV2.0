Ce qu'il faut vérifier

  • float: left sur les li du menu principal, avec un nav à hauteur fixe.
  • position: relative sur les parents, position: absolute sur les .sous-menu.
  • opacity + visibility au niveau 2 : jamais display: none, sinon la transition ne se voit pas.
  • Niveau 3 : top: 0; left: 100% pour l'ouvrir à droite, avec l'animation glisse.
  • La flèche est un <span> en display: inline-block, sans ::after.
