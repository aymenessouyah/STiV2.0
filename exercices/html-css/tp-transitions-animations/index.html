2. Exercice 1 — transitions et animations (niveau simple)

Travail demandé : créer un dossier tp1 contenant index.html et style1.css. Contrainte : pas de display: flex.

Partie A — les transitions (:hover)

A.1-2 · le bouton qui réagit au survol

Au survol : le fond change, le bouton grossit (scale(1.1)) et une ombre apparaît, en 0,4 s.

.btn {
  background: #2980b9; color: #fff;
  padding: 12px 24px; border: none; border-radius: 8px;
  transition: background 0.4s ease-in-out, transform 0.4s ease, box-shadow 0.4s ease;
}
.btn:hover {
  background: #e67e22;
  transform: scale(1.1);
  box-shadow: 0 6px 12px rgba(0, 0, 0, 0.3);
}

transition s'écrit sur l'état de base .btn, jamais dans :hover : sinon le retour est instantané.

A.3-4 · la carte qui se soulève (et le transition-delay)
Je me soulève au survol
.carte {
  width: 220px; padding: 20px; background: #fff; border-radius: 10px;
  box-shadow: 0 2px 5px rgba(0, 0, 0, 0.2);
  transition: transform 0.3s linear, box-shadow 0.3s linear;
  transition-delay: 0.1s;
}
.carte:hover {
  transform: translateY(-10px);
  box-shadow: 0 12px 20px rgba(0, 0, 0, 0.35);
}

translateY(-10px) remonte la carte de dix pixels ; une ombre plus large donne l'impression qu'elle décolle.

A.4 · les fonctions de temporisation, côte à côte

Survolez chaque carré : la durée est la même (1 s), seule la vitesse change.

ease
linear
ease-in-out

  • ease : départ doux, milieu rapide, arrivée douce (le défaut).
  • linear : vitesse constante, du début à la fin.
  • ease-in-out : lent au départ, rapide au milieu, lent à l'arrivée.

Partie B — les animations (@keyframes)

B.1 · le cercle qui pulse 
@keyframes pulse {
  0%   { transform: scale(1); }
  50%  { transform: scale(1.3); }
  100% { transform: scale(1); }
}
.cercle {
  width: 100px; height: 100px; border-radius: 50%; background: #27ae60;
  animation: pulse 1.5s ease-in-out infinite;
}

infinite relance l'animation sans fin ; le cercle revient exactement à son état de départ, donc la boucle est invisible.

B.2 · le loader qui tourne 
@keyframes tourne {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}
.loader {
  width: 60px; height: 60px; background: #8e44ad;
  animation: tourne 1.2s linear infinite;
}

from / to est le raccourci de 0% / 100%. Pour une rotation continue, linear est obligatoire, sinon on voit des à-coups.

B.3 · le titre qui apparaît en fondu

Transitions et animations CSS

h1 { animation: fondu 2s ease; }
@keyframes fondu {
  from { opacity: 0; }
  to   { opacity: 1; }
}
/* Rejouer une animation en JavaScript : on la retire puis on la remet */
function relancerFondu() {
  var t = document.getElementById('titreFondu');
  t.style.animation = 'none';
  void t.offsetWidth;          /* force le navigateur à recalculer */
  t.style.animation = 'fondu 2s ease';
}

Partie C — bonus : la balle qui rebondit

C · animation-direction: alternate 
@keyframes rebond {
  from { transform: translateY(0); }
  to   { transform: translateY(-70px); }
}
.balle {
  width: 40px; height: 40px; border-radius: 50%; background: #c0392b;
  animation: rebond 0.6s ease-in infinite alternate;
}

alternate joue l'animation à l'aller puis à l'envers : la balle remonte et redescend, sans saut visible.

Le soulignement jaune des liens du menu est une border-bottom animée, pas un ::after.

Partie B · le menu principal, en float 
nav { height: 50px; background: #2c3e50; }
.menu { list-style: none; }
.menu > li { float: left; position: relative; }
nav a {
  display: block; padding: 15px 22px; color: #ecf0f1; text-decoration: none;
  transition: background 0.3s ease, padding-left 0.3s ease, border-color 0.3s ease;
}
nav a:hover { background: #e67e22; }

float: left place les entrées côte à côte ; comme les flottants sortent du flux, le nav doit garder une hauteur fixe (50 px).

Partie C · les sous-menus : opacity + visibility 
.sous-menu {
  position: absolute; top: 100%; left: 0; width: 190px; background: #34495e;
  opacity: 0; visibility: hidden; transform: translateY(10px);
  transition: opacity 0.3s ease, transform 0.3s ease, visibility 0.3s;
}
li:hover > .sous-menu {
  opacity: 1; visibility: visible; transform: translateY(0);
}

L'astuce du TP : on ne met pas display: none, car un élément caché ainsi ne peut pas être animé. opacity + visibility le rendent invisible et cliquable-non, tout en gardant la transition.

Partie C.4 et D.3 · le niveau 3, à droite, animé par @keyframes 
.sous-menu .sous-menu {
  display: none; top: 0; left: 100%;
  opacity: 1; visibility: visible; transform: none; transition: none;
}
.sous-menu li:hover > .sous-menu { display: block; animation: glisse 0.4s ease; }
@keyframes glisse {
  from { opacity: 0; transform: translateX(-20px); }
  to   { opacity: 1; transform: translateX(0); }
}

Le niveau 3 part de left: 100%, donc à droite de son parent. Ici display: none est accepté, parce que l'apparition est jouée par une animation, pas par une transition.

Partie D.1-2-4 · la flèche, le décalage et le soulignement 
.fleche { display: inline-block; margin-left: 6px; font-size: 12px; transition: transform 0.3s ease; }
li:hover > a .fleche { transform: rotate(180deg); }

.sous-menu a:hover { padding-left: 32px; }        /* D.2 : le lien glisse */

.menu > li > a { border-bottom: 3px solid transparent; }
.menu > li > a:hover { border-bottom-color: #f1c40f; }   /* D.4 */

Piège du bac : sans display: inline-block (ou block), un <span> ignore transform : la flèche ne tourne pas.

Partie E · bonus : le menu adaptatif 
@media (max-width: 768px) {
  nav { height: auto; }
  .menu > li { float: none; }
  .sous-menu, .sous-menu .sous-menu {
    position: static; width: 100%;
    opacity: 1; visibility: visible; transform: none; display: none;
  }
  li:hover > .sous-menu, .sous-menu li:hover > .sous-menu { display: block; }
}

Sur un petit écran, le menu passe en colonne et les sous-menus s'ouvrent dans le flux, sans se superposer.
