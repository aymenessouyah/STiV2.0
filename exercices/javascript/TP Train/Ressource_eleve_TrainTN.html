Le scénario

Samedi, Sami veut rendre visite à sa grand-mère à Sousse. Il ouvre le site de réservation, remplit le formulaire… Mais un robot essaie de réserver tous les billets ! Le JavaScript calcule le prix, bloque les robots avec un captcha et, au moment d’envoyer, vérifie tout le formulaire.

Règles du code let (pas de var), pas d’expression ternaire, des boucles, innerHTML dans des <output>, substr, alert, prompt, style, disabled, Math.random, un tableau de couleurs, et seulement getElementById / getElementsByName.
Les 5 scènes 1 Identité · 2 Voyage · 3 Prix · 4 Captcha · 5 Envoi (verif()). Chaque scène correspond à une gare du bandeau de progression.

Scène 1Sami arrive sur le site

Le site lui demande qui il est. Sami tape son nom n’importe comment…

  1. demanderNom() : prompt pour demander le nom, placé dans le champ.
  2. emailValide(mail) : boucle qui cherche le @ puis le dernier . (substr) ; retourne true ou false.
  3. identite() : nom avec la 1ère lettre en majuscule (substr), e-mail contrôlé, champs verts ou rouges (style), alert si le nom est vide.

Scène 2Le voyage : quand, à quelle heure ?

Sami choisit samedi à 8 h 15. Le trajet dure 135 minutes : à quelle heure arrivera-t-il ? Combien de jours lui reste-t-il pour annuler ?

  1. typeVoyage() : la date de retour est bloquée (disabled) tant que « Aller-retour » n’est pas choisi.
  2. dateDe(texte) : transforme « aaaa-mm-jj » en objet Date (substr + parseInt).
  3. voyage() : jour de la semaine, jours restants, date limite d’annulation (2 jours avant, setDate), heure d’arrivée (attention au changement de jour), nuits sur place si retour, et avec une boucle les 3 mêmes départs des semaines suivantes.
Heure → minutes : parseInt(h.substr(0, 2)) * 60 + parseInt(h.substr(3, 2)). Minutes → heure : Math.floor(t / 60) et t % 60.

Scène 3Le prix du billet

Les prix sont des textes dans la liste (« 12.500 »). Pour calculer, il faut les convertir ! Et les enfants et les jeunes ont une réduction.

  1. prix() : convertir le prix (parseFloat) et le nombre de billets (parseInt), contrôler avec isNaN.
  2. 1ère classe = prix × 1,5 ; options cochées additionnées par une boucle.
  3. Âge (avec dateDe) : moins de 12 ans → −50 %, de 12 à 25 ans → −25 %, sinon plein tarif (if / else if).
  4. Total avec 3 décimales (toFixed), doublé si aller-retour, et le même montant en millimes (entier).

Scène 4Le robot : le captcha

Pour bloquer le robot, Sami doit recopier un code de 5 caractères dont chaque caractère a sa propre couleur.

Cacher n° 1 : <input type="hidden">Jamais affiché. Il garde une valeur (le code, les essais, « captcha réussi »), lue et modifiée avec .value grâce à getElementsByName("…")[0].
Cacher n° 2 : l’attribut hiddenCache n’importe quelle balise. Le JavaScript l’affiche ou la cache avec element.hidden = false ou true.
  1. Un tableau de 5 couleurs : ["red", "green", "blue", "yellow", "black"].
  2. genererCaptcha() : boucle de 5 tours ; à chaque tour, un caractère au hasard (substr sur CARS) et une couleur prise au hasard dans le tableau (COULEURS[Math.floor(Math.random() * COULEURS.length)]) ; affichage avec innerHTML (<span style="color: …">). Le code en clair va dans le champ hidden codeCache.
  3. verifierCaptcha() : comparer la saisie au code caractère par caractère (boucle + substr). Code juste : captchaOk passe à « 1 », le bloc du captcha se cache et la scène 5 apparaît. Code faux : message d’erreur, un essai de moins, nouveau code ; à 0 essai : disabled et alert.
  4. aide() : affiche ou cache le conseil (si caché → afficher, sinon → cacher).
Un champ hidden se voit dans l’inspecteur du navigateur : dans un vrai site, le code doit être vérifié côté serveur (PHP, session).

Scène 5L’envoi : verif()

Sami clique sur « Confirmer la réservation ». Avant tout, le site vérifie le formulaire et lui montre toutes ses erreurs d’un seul coup.

  1. Le formulaire appelle onsubmit="return verif()".
  2. verif() range les erreurs dans un tableau : champs obligatoires non remplis (boucle sur un tableau de champs), e-mail invalide, date de départ passée, retour manquant ou avant le départ, durée ou nombre de billets invalides, captcha non validé, conditions non acceptées.
  3. S’il y a des erreurs : une seule alert qui les liste (boucle), puis return false. Sinon : reserver() génère le numéro (« TN » + jour et mois + 4 caractères au hasard) et colore le billet.
Dans un vrai site, verif() retournerait true pour envoyer les données vers reservation.php. Ici on retourne false pour rester sur la page.
