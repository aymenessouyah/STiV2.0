Le projet en une phrase

Sami veut réserver un billet de train : on l’accueille, on lui demande son identité, on compose le voyage (dates, horaires, gare), on calcule le prix, on écarte les robots avec un captcha, puis on envoie la réservation. Cinq scènes, un seul fichier JavaScript.

  • 1 · Identité
  • 2 · Voyage et dates
  • 3 · Prix
  • 4 · Captcha
  • 5 · Validation finale

Comment travailler ce TP

  1. Lire les ressources : le scénario et le squelette du fichier.
  2. Faire l’énoncé scène par scène, en testant à chaque étape.
  3. Comparer seulement ensuite avec le corrigé, fonction par fonction.
  4. Regarder la vidéo de correction : le diagramme de chaque partie, puis le code écrit devant soi.
  5. Reprendre les questions ratées dans le quiz JavaScript et le « Retravailler mes erreurs ».
