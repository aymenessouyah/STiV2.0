Travaux Pratiques N°2

Objectifs de la séance :

  • Maîtriser les déclencheurs d'événements JavaScript sur les éléments HTML.
  • Utiliser les méthodes d'accès et de modification du DOM (getElementById, innerHTML, value).
  • Comprendre les différences clés entre événements réactifs (ex: oninput vs onchange).

Activité 1 : Manipulation des Événements Prédéfinis

Consulter, saisir et tester les 8 exemples de codes suivants :

Exemple 1 & 2 : Survol et Changement de valeur

<!-- Code 1 : Survol de la souris --> <img onmouseover="alert('***La seule manière de faire du bon travail, c\'est d\'aimer ce que vous faites.***')" src="smiley.gif"/> <!-- Code 2 : Perte de focus avec changement --> <input type="text" onchange="document.write('Votre numéro est ' + this.value)"/>

Exemple 3 : Saisie en temps réel (différence entre onchange et oninput)

<input type="text" id="saisir" oninput="myFunction()"/> <p id="resultat">Le résultat sera affiché ici</p> <script> function myFunction() { var x = document.getElementById("saisir").value; document.getElementById("resultat").innerHTML = "Vous écrivez : " + x; } </script>

Exemples 4 & 5 : Gestion du Clavier (onkeydown, onkeyup)

<!-- Code 4 --> <input type="text" onkeydown="alert('Touche enfoncée !')"/> <!-- Code 5 : Conversion automatique en majuscules en cours de frappe --> <input type="text" id="TextP" onkeyup="this.value = this.value.toUpperCase()"/>

Exemples 6, 7 & 8 : Prise de focus, Perte de focus et Chargement de page

<!-- Code 6 : Focus --> <input type="text" onfocus="alert('Numéro à 6 chiffres obligatoire')" /> <!-- Code 7 : Blur --> <input type="text" id="fname" onblur="this.value = this.value.toUpperCase()" /> <!-- Code 8 : Load --> <body onload="console.log('Page complètement chargée dans la console')">
