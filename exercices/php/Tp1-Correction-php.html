Exercice n°1 — Fonction d'affichage en rouge

<?php
imprimeEnGras("Cette ligne est en rouge <br/>\n");
print("Cette ligne n'est pas en rouge<br/>\n");
// La fonction peut être placée dans un fichier séparé inclus par include ou require

function imprimeEnGras($monTexte)
{
    $texteEnRouge = "<font color=red>";
    $texteEnRouge .= $monTexte;
    $texteEnRouge .= "</font>";
    print($texteEnRouge);
}
?>

Exercice n°3 — Affichage des jours de la semaine avec foreach

<?php
$semaine = array('Lundi', 'Mardi', 'Mercredi', 'Jeudi', 'Vendredi', 'Samedi', 'Dimanche');

foreach ($semaine as $val)
{
    printf($val);
    print "<br/>";
}
?>
