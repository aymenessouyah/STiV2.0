Série d'Exercices N°4 : PHP & MySQLi Procédural (Table eleves)

Base de données : Soit une base de données nommée bd_ecole contenant la table eleves :
eleves (Id VARCHAR(10), Nom_prenom VARCHAR(60), Moyenne DECIMAL(4,2), DateNaissance DATE)
Règle : Chaque Id commence par une lettre majuscule représentant la Catégorie de l'élève (ex : A101 → Catégorie A). Dans Nom_prenom, le Nom et le Prénom sont séparés par un espace.

Travail Demandé

  1. Connexion à la base (connexion.php) : Écrire un script PHP procédural permettant de se connecter à la base bd_ecole sur le serveur local (localhost, utilisateur root, mot de passe vide "") à l'aide de mysqli_connect().
  2. Inscription d'un élève (inscription.php) : À partir d'un formulaire envoyant $_POST["id"], $_POST["np"], $_POST["moy"] et $_POST["dn"] :
    • Vérifier d'abord avec une requête SELECT et mysqli_num_rows($res) si l'identifiant Id existe déjà dans la table eleves.
    • S'il n'existe pas, insérer le nouvel élève avec INSERT INTO eleves et confirmer l'insertion grâce à mysqli_affected_rows($con).
  3. Affichage et parcours des résultats (liste.php) :
    • Exécuter une requête SELECT récupérant tous les élèves ayant une moyenne supérieure ou égale à 10, triés par Catégorie (initiale de Id).
    • Expliquer la différence entre mysqli_fetch_row($res), mysqli_fetch_assoc($res) et mysqli_fetch_array($res), puis afficher les élèves dans un tableau HTML en séparant le Nom et le Prénom par l'espace.
  4. Comptage des enregistrements (statistiques.php) : Montrer les deux méthodes permettant d'obtenir le nombre d'élèves admis (Moyenne >= 10) :
    • Méthode A : avec SELECT * et mysqli_num_rows($res).
    • Méthode B : avec SELECT COUNT(*) AS nb et lecture de $lig["nb"] via mysqli_fetch_assoc($res).
  5. Mise à jour et fermeture : Écrire l'instruction permettant d'augmenter de 0.5 point la moyenne de l'élève d'identifiant 'A101', afficher le nombre de lignes modifiées, puis fermer la connexion avec mysqli_close($con).
