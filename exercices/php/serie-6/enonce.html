FICHE DE RÉVISION — PHP PROCÉDURAL

1. Variables et constantes : $x = 2.3; define("TVA", 0.19); echo $x . " / " . TVA;
gettype($x) donne le type ; settype($x, "integer") modifie la variable. is_string, is_array, is_float (is_double, is_real), is_int (is_integer, is_long) testent son type. isset teste l'existence d'une valeur non nulle, unset supprime la variable. (int), (float) et (string) convertissent une valeur. include insère un fichier ; require est adapté à une configuration indispensable ; die arrête le script avec un message.

2. Chaînes : les indices commencent à zéro. substr extrait, trim supprime les espaces aux extrémités, strlen compte les octets, str_replace remplace, chr et ord convertissent caractère ASCII et code, strpos cherche une position (comparer strictement à false), strcmp compare et strcasecmp compare en ignorant la casse. strrev inverse les octets ; strtolower et strtoupper modifient la casse ASCII. Pour des caractères accentués, les fonctions sur octets ne suffisent pas nécessairement. Concaténer avec le point ; parcourir les caractères avec for pour séparer ou assembler des éléments.

3. Tableaux : $t = [12, 8, 15]; $s = ["nom" => "Rim", "age" => 17]; count et sizeof comptent les éléments. sort et rsort trient les valeurs et réindexent ; ksort et krsort trient les clés en conservant les associations. Pour un tableau associatif : reset($s); while (key($s) !== null) { echo key($s) . current($s); next($s); }. current et pos lisent la valeur, key lit la clé ; reset, end, next, prev déplacent le pointeur.

4. Formulaires et contrôles : GET transmet les champs dans l'URL ; POST les transmet dans le corps de la requête. Contrôler isset et la validité avant de traiter ; les boutons radio d'un même groupe partagent un name. if / else, switch, for et while structurent les traitements. Échapper les valeurs affichées dans une page HTML avec htmlspecialchars.

5. MySQLi procédural : mysqli_connect ouvre la connexion ; mysqli_select_db choisit la base ; mysqli_query exécute la requête. Pour SELECT, mysqli_num_rows compte les résultats et mysqli_fetch_array ou mysqli_fetch_row lit une ligne à la fois. Pour une modification, mysqli_affected_rows indique le nombre de lignes modifiées ; mysqli_insert_id donne l'identifiant généré par la dernière insertion ; mysqli_error décrit une erreur. En application réelle, utiliser des requêtes préparées pour les données utilisateur, ne pas exposer les erreurs ni les identifiants de connexion.

6. Dates : date formate un timestamp ; time fournit l'instant courant ; getdate donne ses composantes ; checkdate vérifie mois, jour, année ; mktime construit un timestamp local ; strtotime interprète une date textuelle et peut renvoyer false. Fixer le fuseau avec date_default_timezone_set("Africa/Tunis"). Les résultats dépendent de la date et du fuseau.

COMPLÉMENTS — APPLICATION DE L'ANNEXE
A. Prédire les types et les valeurs : $x = "12.5"; afficher gettype($x), puis convertir $x en entier et afficher sa valeur et is_int($x).
B. Pour $s = "  Bac SI  ", afficher la longueur après trim, les trois premiers caractères, remplacer SI par Info, puis comparer "BAC" et "bac" avec strcasecmp. Donner chr(65) et ord("A").
C. Avec $t = ["b" => 2, "a" => 1], trier les clés dans l'ordre croissant, puis afficher clé et valeur à l'aide du pointeur. Afficher aussi le nombre d'éléments.
D. Vérifier le 29 février 2024 avec checkdate, puis créer le timestamp de midi le 25 décembre 2026 à Tunis avec mktime et l'afficher en Y-m-d H:i. Obtenir le tableau des composantes avec getdate.

mysqli_report(MYSQLI_REPORT_OFF); : depuis PHP 8.1, sans cette ligne une erreur MySQL lève une exception
au lieu de renvoyer false et or die(...) n'est jamais exécuté. Adapter UTIL et MDP à votre serveur (en général
root et un mot de passe vide avec XAMPP).
