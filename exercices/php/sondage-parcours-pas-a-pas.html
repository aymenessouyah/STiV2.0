Code complet de sondage.php (MySQLi)

À retenir dans ce code

  • mysqli_affected_rows($badge) (lignes 20, 27 et 39) : renvoie le nombre de lignes affectées par la dernière requête INSERT ou UPDATE, et vaut -1 uniquement en cas d'erreur de la requête SQL.
  • Après plusieurs UPDATE successifs, mysqli_affected_rows($badge) ne reflète que le dernier UPDATE exécuté (et vaut 0 si la nouvelle valeur est identique à l'ancienne). Le test != -1 vérifie donc qu'aucune erreur SQL ne s'est produite.
  • $req4 (ligne 24) vérifie l'existence de idparticipant avant l'insertion des 3 réponses. Pour récupérer l'identifiant auto-incrémenté juste après un INSERT, on peut aussi utiliser mysqli_insert_id($badge).
