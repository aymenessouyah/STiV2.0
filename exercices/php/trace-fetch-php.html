⚖️ Comparaison visuelle : mysqli_num_rows($res) vs SELECT COUNT(*) AS nb

      

        

          
✅ Méthode A : SELECT classique + mysqli_num_rows($res)

          
$req = "SELECT * FROM eleves WHERE Moyenne >= 10";
$res = mysqli_query($con, $req);
// $res contient 4 lignes (A101, A104, B201, C302)
$nbAdmis = mysqli_num_rows($res); // Vaut 4 !
echo "Nombre d'admis : " . $nbAdmis;

          

            👉 Quand l'utiliser ? Quand la requête ne contient pas COUNT(*) et que l'on veut savoir combien d'enregistrements ont été trouvés (ou vérifier si un identifiant existe avec mysqli_num_rows($res) > 0).
          

        

        

          
✅ Méthode B : SELECT COUNT(*) AS nb + fetch

          
$req = "SELECT COUNT(*) AS nb FROM eleves WHERE Moyenne >= 10";
$res = mysqli_query($con, $req);
// ⚠️ $res contient TOUJOURS 1 seule ligne avec la colonne 'nb' !
// mysqli_num_rows($res) vaudrait 1 (PIÈGE DU BAC !)
$lig = mysqli_fetch_assoc($res); // ou mysqli_fetch_row($res)
$nbAdmis = $lig["nb"];           // Vaut 4 !
echo "Nombre d'admis : " . $nbAdmis;

          

            👉 Règle d'or du Bac : Avec SELECT COUNT(*) AS nb, il faut toujours extraire l'unique ligne avec mysqli_fetch_assoc($res) (puis lire $lig["nb"]) ou mysqli_fetch_row($res) (puis lire $lig[0]).
