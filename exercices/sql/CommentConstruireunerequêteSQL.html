Construire une requête SQL

Pars de la question. Remplis les étapes dans l’ordre : la requête s’écrit à droite, et des remarques t’aident à la corriger.

Les 5 questions à se poser
ÉtapeQuestion à se poserMots-clés repérables dans l’énoncéClause obtenue
1Que veut-on afficher ?« afficher », « donner », « lister », « quel est »SELECT
2Dans quelles tables se trouvent ces informations ?noms d’entités : classe, élève, noteFROM + jointure dans le WHERE
3Faut-il filtrer des lignes ?« dont », « de la classe X », « supérieur à », « en 2025 »WHERE
4Faut-il calculer par paquet ?« par classe », « pour chaque », « moyenne / nombre / total de »GROUP BY + agrégat
5Faut-il filtrer sur le résultat du calcul ?« dont la moyenne dépasse », « ayant plus de 3 »HAVING

Étape finale : « du plus grand au plus petit », « trié par » → ORDER BY.

Règles : jointure écrite dans le WHERE sous la forme table1.a = table2.a (pas de JOIN) · aucune fonction (COUNT, AVG…) dans le WHERE : elles vont dans le HAVING.
Schéma de la base

Une table par ligne : table(colonne1, colonne2). La clé primaire s’appelle id, la clé étrangère id_table.
