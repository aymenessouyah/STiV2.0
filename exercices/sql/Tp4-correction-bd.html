Corrigé de la Série de Révision

Rappel du schéma de la base de données ÉTUDIANT :
ETUDIANT (Numetu, Nometu, Dtnaiss, #Cdsexe) • SEXE (Cdsexe, Lbsexe) • ENSEIGNANT (Numens, Nomens, Grade, Ancien) • MATIERE (Numat, Nomat, Coeff, #Numens) • NOTES (#Numetu, #Numat, Note)

  1. Requête 1 : Afficher quel était l'âge moyen des garçons et des filles au premier janvier 2025. 
    SELECT S.Lbsexe, AVG(DATEDIFF('2025-01-01', E.Dtnaiss) / 365) AS "Age Moyen"
FROM SEXE S, ETUDIANT E
WHERE E.Cdsexe = S.Cdsexe
GROUP BY S.Cdsexe, S.Lbsexe;
    Jointure E.Cdsexe = S.Cdsexe (forme a.x = b.x) entre ETUDIANT et SEXE, puis regroupement par sexe avec calcul de la moyenne d'âge au 2025-01-01.
  2. Requête 2 : Afficher le nom et le grade des enseignants d'histoire. 
    SELECT E.Nomens, E.Grade
FROM ENSEIGNANT E, MATIERE M
WHERE E.Numens = M.Numens
  AND M.Nomat = 'Histoire';
    Jointure E.Numens = M.Numens et restriction sur la matière 'Histoire'.
  3. Requête 3 : Afficher les noms et numéro des étudiants qui n'ont pas de notes en Sociologie. 
    SELECT E.Nometu, E.Numetu
FROM ETUDIANT E
WHERE E.Numetu NOT IN (
  SELECT N.Numetu
  FROM NOTES N, MATIERE M
  WHERE N.Numat = M.Numat
    AND M.Nomat = 'Sociologie'
);
    La sous-requête récupère les numéros des étudiants ayant une note en 'Sociologie', et NOT IN sélectionne ceux qui n'y figurent pas.
  4. Requête 4 : Afficher le nom et le coefficient des matières qui sont enseignées par des maîtres de conférences ou des assistants. 
    SELECT M.Nomat, M.Coeff
FROM MATIERE M, ENSEIGNANT E
WHERE M.Numens = E.Numens
  AND E.Grade IN ('MCF', 'Assistant');
    Ou avec les libellés complets : AND E.Grade IN ('Maître de conférences', 'Assistant') (ou AND (E.Grade = 'MCF' OR E.Grade = 'Assistant')). Attention : ne pas mettre 'PR' qui désigne les Professeurs.
  5. Requête 5 : Afficher pour chaque étudiant (nom et numéro), et par ordre alphabétique, la moyenne qu'il a obtenue dans chaque matière. 
    SELECT E.Nometu, E.Numetu, M.Nomat, AVG(N.Note) AS Moyenne
FROM ETUDIANT E, NOTES N, MATIERE M
WHERE E.Numetu = N.Numetu
  AND N.Numat = M.Numat
GROUP BY E.Numetu, E.Nometu, M.Numat, M.Nomat
ORDER BY E.Nometu ASC;
  6. Requête 6 : Afficher le nom, l'âge et le sexe des étudiants qui ont eu une note d'informatique supérieure à la moyenne générale de la classe. 
    SELECT E.Nometu, DATEDIFF(CURRENT_DATE, E.Dtnaiss) / 365 AS Age, S.Lbsexe
FROM ETUDIANT E, SEXE S, NOTES N, MATIERE M
WHERE E.Cdsexe = S.Cdsexe
  AND E.Numetu = N.Numetu
  AND N.Numat = M.Numat
  AND M.Nomat = 'Informatique'
  AND N.Note > (
    SELECT AVG(N2.Note)
    FROM NOTES N2, MATIERE M2
    WHERE N2.Numat = M2.Numat
      AND M2.Nomat = 'Informatique'
  );
    Si l'on compare à la moyenne générale de la classe toutes matières confondues (pondérée par les coefficients), la sous-requête s'écrit : (SELECT SUM(N2.Note * M2.Coeff) / SUM(M2.Coeff) FROM NOTES N2, MATIERE M2 WHERE N2.Numat = M2.Numat).
  7. Requête 7 : Afficher, pour chaque étudiant (nom et numéro) qui a une note dans chacune des matières, la moyenne obtenue au diplôme. 
    SELECT E.Nometu, E.Numetu, SUM(N.Note * M.Coeff) / SUM(M.Coeff) AS Moyenne
FROM ETUDIANT E, NOTES N, MATIERE M
WHERE E.Numetu = N.Numetu
  AND N.Numat = M.Numat
GROUP BY E.Numetu, E.Nometu
HAVING COUNT(DISTINCT N.Numat) = (SELECT COUNT(*) FROM MATIERE)
ORDER BY E.Nometu ASC;
    La condition HAVING COUNT(DISTINCT N.Numat) = (SELECT COUNT(*) FROM MATIERE) garantit que l'étudiant possède une note dans toutes les matières enregistrées dans la table MATIERE.
  8. Requête 8 : Afficher le nom, le grade et l'ancienneté des enseignants qui enseignent dans plus d'une matière. 
    SELECT E.Nomens, E.Grade, E.Ancien
FROM ENSEIGNANT E, MATIERE M
WHERE E.Numens = M.Numens
GROUP BY E.Numens, E.Nomens, E.Grade, E.Ancien
HAVING COUNT(M.Numat) > 1;
    On regroupe par E.Numens (clé primaire de l'enseignant) afin d'éviter toute confusion en cas d'homonymie sur Nomens, puis on filtre avec HAVING COUNT(M.Numat) > 1.
  9. Requête 9 : Afficher le nombre de garçons et le nombre de filles qui ont réussi au diplôme : moyenne >= 10. 
    SELECT S.Lbsexe, COUNT(E.Numetu) AS Nb_Reussis
FROM SEXE S, ETUDIANT E
WHERE S.Cdsexe = E.Cdsexe
  AND E.Numetu IN (
    SELECT N.Numetu
    FROM NOTES N, MATIERE M
    WHERE N.Numat = M.Numat
    GROUP BY N.Numetu
    HAVING SUM(N.Note * M.Coeff) / SUM(M.Coeff) >= 10
       AND COUNT(DISTINCT N.Numat) = (SELECT COUNT(*) FROM MATIERE)
  )
GROUP BY S.Cdsexe, S.Lbsexe;
    Le nombre total de matières est déterminé dynamiquement par (SELECT COUNT(*) FROM MATIERE) (au lieu d'une valeur fixe codée en dur).
  10. Requête 10 : Afficher le nom, le numéro et le sexe des étudiants qui ont une note en informatique supérieure à leur note de Mathématiques. 
    SELECT E.Nometu, E.Numetu, S.Lbsexe
FROM ETUDIANT E, SEXE S, NOTES N1, MATIERE M1
WHERE E.Cdsexe = S.Cdsexe
  AND E.Numetu = N1.Numetu
  AND N1.Numat = M1.Numat
  AND M1.Nomat = 'Informatique'
  AND N1.Note > (
    SELECT N2.Note
    FROM NOTES N2, MATIERE M2
    WHERE N2.Numat = M2.Numat
      AND M2.Nomat = 'Mathématiques'
      AND N2.Numetu = E.Numetu
  );
    On utilise l'opérateur > (sans ALL) avec des alias distincts (N1, M1 et N2, M2) : ainsi, un étudiant qui n'a pas de note en Mathématiques n'est pas sélectionné à tort.
  11. Requête 11 : Afficher le nom des couples, nom du garçon nom de la fille, dont la différence d'âge ne dépasse pas 6 mois (180 jours). 
    SELECT E1.Nometu AS Nom_Garcon, E2.Nometu AS Nom_Fille
FROM ETUDIANT E1, ETUDIANT E2
WHERE E1.Cdsexe = 'H'
  AND E2.Cdsexe = 'F'
  AND ABS(DATEDIFF(E1.Dtnaiss, E2.Dtnaiss)) <= 180;
    Variante équivalente sans ABS : AND DATEDIFF(E1.Dtnaiss, E2.Dtnaiss) BETWEEN -180 AND 180.
  12. Requête 12 : Pour les étudiants n'ayant pas de note dans une matière, afficher le numéro, le nom de l'étudiant et le nom de la matière concernée. 
    SELECT E.Numetu, E.Nometu, M.Nomat
FROM ETUDIANT E, MATIERE M
WHERE E.Numetu NOT IN (
  SELECT N.Numetu
  FROM NOTES N
  WHERE N.Numat = M.Numat
);
    Pour chaque couple (ETUDIANT E, MATIERE M), la sous-requête corrélée vérifie que E.Numetu ne figure pas parmi les étudiants ayant une note dans la matière M.Numat.
  13. Requête 13 : Afficher les matières pour lesquelles la moyenne des notes est inférieure à 10. Afficher le nom de l'enseignant correspondant. 
    SELECT M.Nomat, E.Nomens, AVG(N.Note) AS Moyenne
FROM ENSEIGNANT E, MATIERE M, NOTES N
WHERE E.Numens = M.Numens
  AND M.Numat = N.Numat
GROUP BY M.Numat, M.Nomat, E.Numens, E.Nomens
HAVING AVG(N.Note) < 10;
  14. Requête 14 : Afficher, pour chaque matière, quelle est la meilleure note et quel est l'étudiant qui l'a obtenue. 
    SELECT M.Nomat, N.Note AS Meilleure_Note, E.Nometu
FROM MATIERE M, NOTES N, ETUDIANT E
WHERE N.Numat = M.Numat
  AND E.Numetu = N.Numetu
  AND N.Note = (
    SELECT MAX(N2.Note)
    FROM NOTES N2
    WHERE N2.Numat = M.Numat
  );
  15. Requête 15 : Afficher, pour chaque sexe (Homme, Femme) la moyenne des notes dans la matière enseignée par Ali Ben Salah. 
    SELECT S.Lbsexe, AVG(N.Note) AS Moyenne
FROM SEXE S, ETUDIANT E, NOTES N, MATIERE M, ENSEIGNANT G
WHERE S.Cdsexe = E.Cdsexe
  AND E.Numetu = N.Numetu
  AND N.Numat = M.Numat
  AND M.Numens = G.Numens
  AND UPPER(G.Nomens) = 'ALI BEN SALAH'
GROUP BY S.Cdsexe, S.Lbsexe;
