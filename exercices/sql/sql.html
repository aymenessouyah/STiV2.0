Partie I — Questions Théoriques, LDD & Analyse

1. QCM SQL général

  1. Quelle est la clé primaire de la table NOTES ?
    • A) Numetu    B) Numat    C) (Numetu, Numat)    D) Note
  2. En quelle unité la fonction DATEDIFF('2025-01-01', Dtnaiss) retourne-t-elle l'écart entre deux dates ?
    • A) Années    B) Mois    C) Jours    D) Heures
  3. Que permet de vérifier la clause HAVING COUNT(DISTINCT Numat) = (SELECT COUNT(*) FROM MATIERE) ?
    • A) Filtrer les notes > 10    B) Retenir les étudiants ayant une note dans toutes les matières    C) Calculer la moyenne générale    D) Trier les matières
  4. Quelle est la différence principale entre les opérateurs IN et EXISTS ?
    • A) Ils sont identiques    B) IN ne prend pas de sous-requête    C) IN compare une valeur à une liste, EXISTS teste l'existence de lignes    D) EXISTS s'utilise sans SELECT
  5. Pourquoi utilise-t-on une sous-requête corrélée pour afficher la meilleure note de chaque matière avec le nom de l'étudiant ?
    • A) Pour calculer la moyenne    B) Pour comparer chaque note au maximum de sa propre matière    C) Pour compter les matières    D) Pour trier par ordre alphabétique

2. Langage de Définition des Données (LDD)

  1. Que signifie l'acronyme LDD et quelles sont ses principales commandes SQL ?
  2. Écrire la commande SQL permettant de créer la table MATIERE (Numat INT, Nomat VARCHAR(50), Coeff INT, Numens INT) avec sa clé primaire et sa clé étrangère vers ENSEIGNANT(Numens).
  3. Écrire la commande permettant d'ajouter une colonne DateEvaluation de type DATE à la table NOTES.
  4. Quelle est la différence entre DROP TABLE et TRUNCATE TABLE ?
  5. Écrire la commande permettant de modifier le type de la colonne Note de la table NOTES en DECIMAL(5,2).
  6. Écrire la commande permettant d'ajouter une contrainte CHECK sur la colonne Note (comprise entre 0 et 20) dans la table NOTES.
  7. Écrire la commande permettant de supprimer la contrainte de clé étrangère fk_matiere_enseignant dans la table MATIERE.

3. Vrai / Faux

  1. SELECT * FROM ETUDIANT WHERE Cdsexe = 'H'; affiche tous les garçons.
  2. Le mot-clé DISTINCT placé après SELECT permet d'éliminer les lignes en double.
  3. La clause WHERE peut contenir directement une fonction d'agrégation comme AVG(Note).
  4. Une sous-requête corrélée fait référence à une colonne de la requête principale.
  5. Une requête portant sur deux tables sans condition de jointure WHERE a.x = b.x produit un produit cartésien.

Partie II — Travail Pratique : Requêtes LMD sur la base ÉTUDIANT

Exprimer en SQL les requêtes suivantes (en utilisant uniquement des jointures dans la clause WHERE) :

  1. Afficher le nom et la date de naissance des étudiants nés après le 01/01/2004.
  2. Afficher le code sexe et le nombre d'étudiants pour chaque sexe.
  3. Afficher le nom et le grade des enseignants qui assurent la matière 'Histoire'.
  4. Afficher le nom et le coefficient des matières enseignées par un enseignant de grade 'MCF' ou 'Assistant'.
  5. Afficher les noms des étudiants ayant obtenu une note strictement supérieure à 15 en 'Mathématiques'.
  6. Afficher les matières dont la moyenne des notes est supérieure ou égale à 12, ainsi que cette moyenne.
  7. Afficher les enseignants (nom, grade, ancienneté) qui enseignent au moins 2 matières.
  8. Afficher l'âge moyen des garçons et des filles au 1er janvier 2025 (avec DATEDIFF('2025-01-01', Dtnaiss) / 365).
  9. Afficher les étudiants (nom et numéro) qui n'ont aucune note dans la matière 'Sociologie'.
  10. Pour chaque étudiant, afficher son nom, son numéro, le nom de la matière et sa moyenne par matière, triés par ordre alphabétique du nom.
  11. Afficher le nom, l'âge et le libellé du sexe des étudiants ayant obtenu en 'Informatique' une note supérieure à la moyenne générale de la matière 'Informatique'.
  12. Afficher les étudiants ayant une note dans toutes les matières, avec leur moyenne générale pondérée par les coefficients (SUM(Note * Coeff) / SUM(Coeff)).
  13. Afficher les étudiants (nom, numéro, libellé sexe) dont la note en 'Informatique' est strictement supérieure à leur propre note en 'Mathématiques'.
  14. Afficher les couples (Nom_Garcon, Nom_Fille) dont la différence d'âge ne dépasse pas 180 jours (ABS(DATEDIFF(...)) <= 180).
  15. Pour chaque matière, afficher le nom de la matière, la meilleure note obtenue et le nom de l'étudiant qui l'a obtenue.
  16. Afficher la moyenne des notes obtenues dans les matières enseignées par 'Ali Ben Salah', regroupée par sexe (Lbsexe).
  17. Augmenter à 4 le coefficient de la matière 'Informatique', puis supprimer les enseignants qui n'enseignent aucune matière.
