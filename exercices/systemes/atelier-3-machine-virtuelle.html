Atelier 3 · 3ᵉ SIATELIER 3 · MÉTHODE

Tester un système sans rien casser.

Cinq exercices sur la virtualisation : définition, schéma, vrai ou faux, intérêt pour un laboratoire et protocole d’installation en cinq étapes.

📦 Commencer l’atelier 📖 Revoir le cours

Objectifs de l’atelier

  • Définir une machine virtuelle et nommer deux logiciels.
  • Expliquer la différence avec une installation classique.
  • Justifier l’usage de la virtualisation au lycée.
  • Ordonner un protocole d’installation.
Atelier 3 — La machine virtuelle0 exercice fait
À faire
01

Comprendre la machine virtuelle

Rappel de cours

Complétez : « Une machine virtuelle est un ordinateur ……… par un logiciel. Elle permet d’installer un système d’exploitation dans une ………, sans ……… le système principal. »

Citez deux logiciels de virtualisation du programme.

Afficher le corrigé

« Une machine virtuelle est un ordinateur simulé par un logiciel. Elle permet d’installer un système d’exploitation dans une fenêtre, sans remplacer le système principal. »

Deux logiciels de virtualisation : VMware et VirtualBox.

02

Le schéma à compléter

Schéma

Complétez la chaîne, du plus concret au plus virtuel :

PC réel (Windows) → ……… → machine virtuelle (Linux)

Sans logiciel de virtualisation, que se passe-t-il si l’on veut tester Linux sur un PC Windows ?

Afficher le corrigé

La case manquante est le logiciel de virtualisation (VMware ou VirtualBox) : il crée la machine virtuelle dans une fenêtre du système réel.

03

Vrai ou faux

Attention aux pièges
  1. Une machine virtuelle est un ordinateur physique supplémentaire.
  2. La machine virtuelle s’exécute dans une fenêtre du système principal.
  3. Une panne dans la machine virtuelle peut empêcher le système principal de démarrer.
  4. La machine virtuelle demande de la mémoire et du processeur au vrai PC.
Afficher le corrigé
  1. Faux : c’est un ordinateur simulé par un logiciel, pas une machine physique de plus.
  2. Vrai : elle s’exécute dans une fenêtre, sans remplacer le système principal.
  3. Faux : elle reste isolée dans une fenêtre ; le système principal continue de fonctionner.
  4. Vrai : les ressources sont prises sur le vrai PC, d’où des machines parfois plus lentes.
04

Pourquoi virtualiser au lycée ?

Situation professionnelle

Le laboratoire d’informatique doit faire essayer Linux à vingt élèves, sans abîmer les postes sous Windows.

  1. Donnez trois avantages de la machine virtuelle dans cette situation.
  2. Citez une limite à surveiller.
  3. Rédigez une consigne de sécurité de deux lignes pour les élèves.
Afficher le corrigé
  1. On teste un autre système sans toucher au système principal ; on peut revenir en arrière en supprimant simplement la VM ; chaque élève travaille dans son propre environnement, isolé des autres.
  2. La machine virtuelle consomme la mémoire, le processeur et le disque du PC réel : elle peut être plus lente.
  3. Exemple : « Ne supprimez jamais le dossier de la machine virtuelle. Enregistrez votre travail dans le dossier partagé du serveur, pas seulement dans la VM. »
05

Protocole d’installation en cinq étapes

Méthode

Remettez dans l’ordre les étapes proposées, de la première à la dernière :

Démarrer la machine virtuelle · Installer le logiciel de virtualisation · Vérifier la connexion réseau de la VM · Créer une nouvelle machine virtuelle et lui attribuer de la mémoire · Installer le système d’exploitation invité.

Afficher le corrigé
  1. Installer le logiciel de virtualisation.
  2. Créer une nouvelle machine virtuelle et lui attribuer de la mémoire.
  3. Installer le système d’exploitation invité.
  4. Démarrer la machine virtuelle.
  5. Vérifier la connexion réseau de la VM.
