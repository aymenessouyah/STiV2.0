💡 Méthode de travail

Conseils pour exceller en STI

01

Commencez par la vidéo, puis testez le code

Regardez la capsule .mp4 pour visualiser l'exécution, puis reproduisez l'exemple vous-même dans le Bac à sable avant de lire le corrigé.

02

Soignez la cohérence HTML ↔ JS ↔ PHP ↔ SQL

Au Bac pratique, vérifiez toujours que les attributs id (pour JS), name (pour PHP) et les noms de colonnes SQL correspondent au caractère près.

03

Exploitez les annexes officielles

Inutile d'apprendre par cœur ce qui figure déjà sur l'annexe du jour de l'examen : entraînez-vous avec l'onglet « Annexes » de chaque cours.

04

Transformez chaque erreur de quiz en point gagné

Relancez chaque semaine le module « Mes erreurs » depuis votre tableau de bord pour ancrer durablement les points subtils.
