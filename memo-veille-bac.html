Fonctions booléennes classiques (`Nom_prenom` : lettres + espaces, 2 à 5 mots)

function nettoyerEspaces(ch) {
  let res = "", precEspace = true;
  for (let i = 0; i < ch.length; i++) {
    if (ch[i] !== " ") { res += ch[i]; precEspace = false; }
    else if (!precEspace) { res += " "; precEspace = true; }
  }
  return res.trim();
}
function verifNomPrenom(ch) {
  let propre = nettoyerEspaces(ch);
  if (propre.length === 0) return false;
  let nbEspaces = 0;
  for (let i = 0; i < propre.length; i++) {
    let c = propre[i].toUpperCase();
    if (c === " ") nbEspaces++;
    else if (c < "A" || c > "Z") return false;
  }
  let nbMots = nbEspaces + 1;
  return (nbMots >= 2 && nbMots <= 5);
}

🗄️ 3. SQL / MySQL (LDD · LMD · LID · Agrégats & Dates)

Création & modification de tables (LDD)

CREATE TABLE eleves (
  Id VARCHAR(10) PRIMARY KEY,
  Nom_prenom VARCHAR(60) NOT NULL,
  Moyenne DECIMAL(4,2) DEFAULT 10.00 CHECK (Moyenne BETWEEN 0 AND 20),
  DateNaissance DATE NOT NULL
);
ALTER TABLE eleves ADD CONSTRAINT chk_moy CHECK (Moyenne >= 0);

Ordre immuable d'une requête `SELECT` & Jointures / Sous-requêtes

SELECT LEFT(Id, 1) AS Categorie, COUNT(*) AS Nb, AVG(Moyenne) AS MoyCat
FROM eleves
WHERE YEAR(DateNaissance) >= 2006
GROUP BY LEFT(Id, 1)
HAVING COUNT(*) >= 2
ORDER BY Categorie ASC;

-- Sous-requête : l'élève ayant la meilleure moyenne
SELECT * FROM eleves
WHERE Moyenne = (SELECT MAX(Moyenne) FROM eleves);

🐘 4. PHP & MySQLi Procédural (`www` / `htdocs` → `http://localhost/`)

Connexion, vérification d'existence et insertion

<?php
$con = mysqli_connect("localhost", "root", "", "bd_lycee");
$id  = $_POST["id"];
$np  = $_POST["np"];
$moy = $_POST["moy"];
$dn  = $_POST["dn"];

$res = mysqli_query($con, "SELECT * FROM eleves WHERE Id = '$id'");
if (mysqli_num_rows($res) > 0) {
  echo "Élève déjà inscrit !";
} else {
  $req = "INSERT INTO eleves VALUES ('$id', '$np', $moy, '$dn')";
  mysqli_query($con, $req);
  if (mysqli_affected_rows($con) > 0) {
    echo "Inscription réussie !";
  }
}
mysqli_close($con);
?>

Différences clés à connaître par cœur au Bac

  • mysqli_fetch_row($res) → tableau indicé numériquement ($t[0], $t[1]).
  • mysqli_fetch_assoc($res) → tableau associatif par nom de colonne ($t["Nom_prenom"]).
  • mysqli_fetch_array($res) → accepte les deux ($t[0] ET $t["Nom_prenom"]).
  • mysqli_num_rows($res) → nombre de lignes retournées par un SELECT (tandis que SELECT COUNT(*) AS nb renvoie 1 ligne dont on lit $t["nb"]).
  • mysqli_affected_rows($con) → nombre de lignes touchées par INSERT, UPDATE ou DELETE.
